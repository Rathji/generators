Seed From URL (Example)

[output]

Add ?seed=yourseedtext to the end of this generator's URL to use a seed. Whenever you load this page with the same seed, you'll see the same "random" results in the exact same order. For example, if you use seed=hello, the first result will always be "I wish I could pat that worm", and the second result will always be "I wish I could help that crayfish".

If you're in edit mode, make sure the ?seed=yourseedtext comes before the #edit part of the URL. So if you want the seed to be "hello", the correct URL would be either of these two:

https://perchance.org/seed-from-url-example?seed=hello

https://perchance.org/seed-from-url-example?seed=hello#edit.

See the seeder-plugin page for details.
