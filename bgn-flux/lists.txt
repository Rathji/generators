//  HOW FLUX WORKS
//  · Stack matching element cards in your rows for points, and cover
//    an opponent's row with a matching card to steal the whole pile.
//  · RIFT cards rewrite the law of the table as they're played:
//    draw more, play fewer, refill bigger, double the points…
//    Keepers (see rulesConfig) set the baseline; Rifts push it around.
//  · Most points when the deck runs out wins. The only constant is change.
//
//  TEMPLATE SETTINGS — deck + rules + branding live below.
//  ═══ THE SERVER MIRROR ═══
//  The online server cannot read main.pjs, so index.html's
//  <script type="text/x-server-plugin"> block carries a MIRROR copy of
//  deckConfig + rulesConfig — including the extra kind/effect fields on
//  Rift cards. KEEP THEM IN SYNC (online play verifies and warns).
//
//  DECK — one entry per card type: [name, emoji, value, count]
//    name    the label shown on the card
//    emoji   the icon drawn on the card face
//    value   points this card is worth in a stack
//    count   copies of this type in the deck (0 = leave it out)
//  Optional 5th & 6th fields turn that type into a real SVG playing
//  card (mixed decks are fine): suit + rank, e.g. "spades","A".
//  Optional 7th field: kind = "rift" marks a card as a RIFT — playing
//  it rewrites a rule instead of stacking it. The 8th field is its
//  effect: ["key", value] where key is one of drawPerTurn,
//  playsPerTurn, emptyHandDraw or scoreMult.
//  Caps: total copies ≤ 64 (MAX_CARDS); ≤ 32 cards per stack.
// ═══════════════════════════════════════════════════════════════════
