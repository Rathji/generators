🧩 SillyTavern Interop

A Perchance plugin that parses and serializes SillyTavern's real file formats — character cards v1/v2/v3, PNG cards with chara/ccv3 chunks, lorebooks, and .jsonl chats — into Perchance-usable structures and back, without dropping data.

What it does

Drop a SillyTavern character card (JSON or PNG with an embedded chara/ccv3 chunk), a lorebook, or a chat log into the demo below. The plugin auto-detects the spec, normalizes it into one canonical shape, and can re-export it as v1/v2/v3 JSON, a PNG with both chara and ccv3 chunks, a lorebook .json, or a .jsonl chat — byte-faithfully.

Notes

  • ccv3 precedence — when a PNG has both chunks, ccv3 wins on import, exactly like SillyTavern. Exports always write both.
  • tEXt-chunk-only writing — card data goes into tEXt chunks as base64 UTF-8 JSON (ST never writes ccv3 into iTXt; we match that).
  • Nothing is dropped — unknown card, extension, entry and message fields survive in legacy buckets and are re-emitted on export.
  • Never a silent failure — every error has a stable .code (see st.errors.codes) and a human-readable message.
