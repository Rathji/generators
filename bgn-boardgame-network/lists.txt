// ─────────────────────────────────────────────────────────────
//  THE BOARDGAME NETWORK (BGN) — HUB
// ─────────────────────────────────────────────────────────────
//  Every game listed below shows up on the hub page as a card.
//  To ADD a game: copy one `game` block and fill it in.
//
//    slug        → REQUIRED. The part of the URL after
//                  perchance.org/  (e.g. "catan" → perchance.org/catan)
//    title       → Name shown on the card.
//    genre       → Shown as a tag chip and used for filtering.
//    blurb       → One-line description under the title.
//    players     → OPTIONAL. e.g. "1–4 players" — shown on the box.
//    color       → OPTIONAL. Accent color for the card's box art.
//                  Any CSS color works (hex, hsl, name). Leave blank
//                  to get an auto-picked color.
//    icon        → OPTIONAL. A single character / emoji / chess glyph
//                  drawn on the box art. Leave blank for an auto one.
//    comingSoon  → OPTIONAL. Set `comingSoon = true` to show the card
//                  as "Coming Soon" on the shelf (not linked yet).
//
//  NOTE: The games below are the current BGN shelf. Add new ones by
//  copying a `game` block and filling it in. Games without a live
//  page yet should set `comingSoon = true`.
//
//  When you add a LIVE game, also add its slug + min players to the
//  GAME_MIN table inside the Lobby server block in index.html — that
//  table is what the matchmaker uses to know when a table is full.
// ─────────────────────────────────────────────────────────────
