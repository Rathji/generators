External Port Scanner

Finds which ports on your external IP are open and reachable from the internet — so you can spot exposed services and port-forwarding mistakes.

How it works: browsers can't open raw TCP connections, so each port is probed by check-host.net's worldwide check nodes (2 locations per port, via the superFetch proxy) and the connection results are collected here. Only run this against IPs you own. Some ISPs use CGNAT, in which case nothing will appear open even if you've forwarded ports. Scans are throttled to respect the free service's rate limits.
