Quick start
Chat with a character: click any card in the gallery to open its profile, then press chat now.
Back to the gallery: press + new chat / character in the sidebar, or the ← back button in the chat header.
Make your own character: press create new character in the gallery (full guide in the editing section below).
Private by default: all characters, chats and memories are stored only in your browser — nothing is uploaded unless you explicitly share a link.
Sending messages
Type a message and press Enter to send; Shift+Enter starts a new line. The AI replies automatically.
Reply as / Narrator: the three buttons above the input (user, character, narrator) put a command into the message box (/user, /character, /narrator). Press send with the command (or with nothing typed) and the AI writes that role's message — your reply, the character's reply, or third-person scene narration.
Slash commands — type / in the input box to open the menu
/as user|char|narratorswitch who you reply as
/usergenerate your (user) message

Images
The Scene image option in the chat header ⋯ menu generates one anime-style image of the current scene from the recent conversation.
The 🖼️ Image shortcut button above the input box generates 3 scene images at once — and it's fully customizable: press the ✏️ button to edit, add, rename or remove shortcut buttons for this conversation (each character can set its own defaults in the character editor).
/image draw a dragon — short requests are blended into the current scene; long detailed descriptions are used exactly as written. /image alone describes the scene itself. Add --num 3 (1–4) for multiple images.
Art characters: ask the AI Artist for a picture and they reply with image tags that become real images inside the chat.
Every generated image has keep (save it permanently) and delete buttons. Kept images live in the 🖼️ saved images gallery (top-left of the gallery page, and the 🖼 button in any chat) — stored privately on your device, with folders, per-character filters, and the real prompt. In Settings you can also enable an AI image for every character reply.
For generating many images outside the chat, use the ai-text-to-image-generator tool linked in the gallery.
Message actions
Hover over any message to reveal actions: copy the text, edit it (fix a typo or rewrite the message), regenerate (only character replies — rerolls the answer) and delete (removes the message and everything that follows).
When you scroll up, a jump-to-latest button appears to return to the newest message.
Memory & summaries
Long chats are automatically summarized in the background (hierarchical summarization) so the AI never forgets earlier parts, and durable "timeless facts" (memories) are extracted and searched semantically at runtime.
Memory mode per chat (the 🧠 option in the chat header ⋯ menu, or /memory): standard (built-in memories from summarization), deep (a small local AI model — one ~25MB download cached by the browser, runs 100% on your device so it's fully private, with stronger recall of old chats), or none.
Creating & editing characters
Character description/instruction/role — the whole character in one box: its personality, behavior, speaking style AND look. Use \{\{char\}\} for the character's name and \{\{user\}\} for your name. Add a # Appearance: section with the physical description (age, hair, eyes, outfit…) — the app reads it for profile display and to keep generated images consistent.
Opening messages (one per line, prefixed char| or user|) start the chat.
Background image URL sets the scene behind the chat.
Custom code (advanced): optional JS that runs in a sandboxed iframe before each reply — return a string to inject extra context (dice rolls, web lookups…).
Image generation (advanced): prompt starter (prepended to every image prompt), prompt ending (appended), and prompt triggers — one per line like keyword: extra text or /regex/: text, auto-added when the description matches.
Lorebook: world facts with trigger keywords (e.g. "castle"). When a keyword appears in the conversation, the fact is blended into the AI's context automatically.
Share link: packs the character into a gzip-uploaded ?data= link — anyone who opens it gets the character added to their app. Duplicate copies the character, delete removes it.
Generate a character from a web page
In the gallery, paste any web page URL and press generate. Character cards from chub.ai, character.ai, janitorai, spicychat.ai, crushon.ai and sakura.fm, plus Wikipedia and Fandom pages, are read with built-in per-site handlers (exact description + avatar extraction, no AI needed for character-card sites). Any other page falls back to the AI reader. You can add optional extra instructions.
Settings
Your profile: your name, your picture (paste a URL or press the 🎨 button to AI-generate one), and an appearance description that builds you into scene images.
AI replies: temperature (higher = more creative/random), max tokens per reply, and response length (short / medium / long).
Chat experience: autoreply (the AI keeps talking on its own), an AI image for every character reply, the default reply as mode, and whether avatars are shown.
This character: per-character overrides for temperature, max tokens and images.
Chat background: pick a built-in tile or upload your own image — or set it instantly with /background \[url\].
Finding things
The sidebar search box filters your conversations (regular expressions allowed). In the gallery, the magnifier next to "Your Characters" searches your character cards.

Export (sidebar) downloads a backup of all your data; import restores it on another device.

Games — play against the character
Open Games from the chat header ⋯ menu (or type /game) to choose an interactive game.
Lucky Dice — best of 3 rounds against the character: press roll dice (the bar above the input) and your roll appears as a real dice face in the chat; the character rolls too. Highest roll wins the round, first to 2 wins the game, and the character reacts to every roll in character. play again starts a rematch.
Higher or Lower — a 5-round duel against the character. The deck shows a number, and you and the character each bet whether the next one goes higher or lower. Right guess = +1 point; most points wins, and a tie goes to sudden death. The character plays back with its own predictions and reacts to every round.
