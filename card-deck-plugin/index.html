🃏 card-deck-plugin

Render clean inline SVG playing cards and card backs by id — outline paths only, no fonts, no external assets. Never throws: an unknown id returns a readable placeholder string.

Import

Add this line to the top of your lists editor:

cardDeck = \{import:card-deck-plugin\}

Basic usage

Call cardDeck(id) anywhere — it returns a full inline <svg> string, ready to drop into your page:

let cardSvg = cardDeck("AS");                 // ace of spades
outputEl.innerHTML = cardSvg;

Every rank and suit is available (52 cards + 2 jokers), plus 16 patterned backs. The list keyword returns all 70 valid ids:

cardDeck("10C")                                 // ten of clubs
cardDeck("QH", \{fourColor:true\})              // queen of hearts in red ink
cardDeck("back", "rosette", "maroon")           // a patterned card back
cardDeck("list")                                // \[\"AS\",\"2S\",...,\"back_dots_plum\"\]

Recolour at runtime

Pass an options object to substitute colours — handy for themed decks, accessible colourways, or matching your generator's palette:

cardDeck("AS", \{ fourColor: true \})   // suits colour-coded (♣/♠ stay black, ♦/♥ red)
cardDeck("AS", \{ ink: "#22d3ee", ground: "#0b0f1a", border: "#334155" \})
cardDeck("back", "chevrons", "pine")   // 4 motifs × 4 colourways = 16 backs

API reference

CallReturns
cardDeck(id)Inline <svg> string for any of the 70 ids
cardDeck(id, opts)Same, recoloured — opts = \{fourColor, ink, ground, border\}
cardDeck("back", motif, colourway)A card back (lattice / rosette / chevrons / dots × navy / maroon / pine / plum)
cardDeck("list")Array of the 70 valid ids

Never throws — an unknown id or back combination returns a (unknown card id: …) / (unknown back motif: …) placeholder string instead of an exception.

Notes

  • 70 assets, one inline payload: 52 cards + 2 jokers + 16 backs (4 motifs × 4 colourways), zero external requests.
  • SVGs are outline paths with a viewBox — scale them freely with CSS, e.g. #cardGrid svg \{ width: 88px; \}.
  • No fonts, no raster images, no external assets — render anywhere, even in contexts where images are blocked.
  • Cards are labelled for accessibility (role="img" + aria-label like "ace of spades").
