Runs

Configure a run, generate endless batches, and let AI QC gate them onto review sheets. Add as many runs as you like.
How to use this tab

1 · Pick or create a run

  • Standard is pre-made — select its tab, or ＋ Add run to make your own (⧉ Duplicate copies the current run, ✕ deletes it).
  • Your runs are saved in the browser, so they survive reloads.

2 · Configure

  • Prompt — what to generate. Negative prompt — things to avoid (watermarks, deformed hands…).
  • Settings — paste a reference image URL to lock in a look/style, and pick the resolution.
  • AI QC gate — when on, every image is checked by AI before it reaches a review sheet; edit the Gate prompt to change the standard.
  • Looks — one composition/look per line; each batch cycles to the next so batches vary.
  • Batch / Sheet — how many images per batch, and how big the numbered review sheets are.
  • Hit 💾 Save run when happy (generation also reads the current form, so edits apply immediately).

3 · Generate

  • ▶ Start — keeps generating batch after batch until you press ⏹ Stop.
  • 🎲 Batch — runs a single batch now.
  • ⏱ Auto-run — runs the number of batches in the box next to it.
  • 🔎 Prompt — shows exactly what will be sent to the image AI before you commit.
  • 🕐 Watchdog — auto-restarts the run when the image service recovers from a block; 🐢 Slow (top bar) paces requests so the service stops flagging you as a bot.

4 · Curate from the grid

  • Under any generated image: ⭐ my pick, 🕊 phoenix (best-of), 🗑 trash, ⬇ save, 🔍 zoom.
  • QC-passed images are pooled into AI picks (capped at 40 per run) and numbered onto a review sheet.

Review Sheets

    
Numbered contact sheets — click an image to zoom, ✅ approve, or ⚰️ slay. Your eye is the final judge.

  

  

    How to use this tab
    

      
What you're looking at

      
    
        
  • Every finished batch becomes a numbered sheet (Run #N) of QC-passed images. Click an image to zoom in.
    • 
        
  • Each image has four buttons: ✅ approve → the Approved collection, ⚰️ slay → the Tomb, 🕊 phoenix → the best-of collection, ⭐ my pick.
    • 
      

      
Whole-sheet actions

      
    
        
  • ✅ Approve on a sheet header approves everything on it at once (click again to un-approve).
    • 
        
  • ✕ hides a sheet from this list (restore later with ↩ Restore hidden auto-sheets).
    • 
        
  • 📕 Collapse all tucks every sheet's thumbnails away for a quick scan.
    • 
      

      
Pro tip — two-tab reviewing

      
    
        
  • Open this generator in a second tab with ?review=1 added to the URL.
    • 
        
  • That tab becomes a read-only review console (no accidental generation) that auto-syncs as you curate on the main tab.
    • 
      

    

  

  
Sheets appear here as runs finish batches (every sheet-size images).

  

    
    
  

  







  

    
⚱ Tomb of the Fallen

    
Discarded images are kept here for 24 hours — recover them before they fade forever.

  

  

    How to use this tab
    

      
How it works

      
    
        
  • Every image you slay (⚰️) or trash (🗑) lands here instead of being deleted outright — a safety net for second thoughts.
    • 
        
  • Each item shows why it was discarded and how long it has left. Items auto-purge 24 hours after they were discarded.
    • 
      

      
Actions

      
    
        
  • ↩ Recover — brings an image back to the Recovered grid below (you can ⭐ pick or ⬇ save it from there). Note: it returns to the Recovered grid, not to its original sheet.
    • 
        
  • 🗑 on an item — purge it immediately and forever.
    • 
        
  • 🗑 Purge all — empties the whole tomb; 🧹 Purge expired — only removes the ones past 24 hours.
    • 
      

      
Tip

      
    
        
  • Recovered images stay in the Recovered grid until you purge them — curate there before the list grows.
    •

⬇ Data

    
Export/import everything (runs, sheets, picks, images) so you can migrate between generators. Large exports split into part files — select them all together when importing.

  

  

    How to use this tab
    

      
Export / Import everything

      
    
        
  • ⬇ Export everything — downloads a JSON file with all runs, sheets, picks, and every stored image. Very large exports split into multiple part files; download them all.
    • 
        
  • ⬆ Import — pick the export file (or all part files at once) to merge everything back in. The page reloads when it's done.
    • 
      

      
Backup / Restore kept images

      
    
        
  • ⬇ Backup kept images — a lighter file containing just your best (approved + my picks + phoenix) — handy for moving between generators or long-term archives.
    • 
        
  • ⬆ Restore kept images — loads that backup back in.
    • 
      

      
Where your data lives

      
    
        
  • Everything is stored locally in this browser (localStorage + IndexedDB). Nothing leaves your machine unless you export — so export regularly if you clear your browser data.

💬 Chat

    
A companion who remembers. Streaming replies · edit her persona below · 🖼️ Scene illustrates the moment

  

  

    How to use this tab
    

      
Talking

      
    
        
  • Type at the bottom and press Enter (or Send) — replies stream in as they're written.
    • 
        
  • The companion remembers the conversation; long chats are automatically summarized to keep it coherent.
    • 
        
  • 🔄 New chat clears the log (history stays saved until you send again); 💾 Save log downloads the conversation.
    • 
      

      
Make it yours

      
    
        
  • Edit Name, Scene style, and the Persona box (the full personality/system prompt) above, then 💾 Save persona. ↺ Default restores the built-in persona.
    • 
        
  • This companion is deliberately generic — write any persona you like and it will play that character.
    • 
      

      
Scenes

      
    
        
  • 🖼️ Scene generates an image of the current moment in the chat, using the scene style you set — like a book cover for your conversation.
