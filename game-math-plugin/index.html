🃏 Deck odds (hypergeometric)

Odds of drawing exactly k copies of a card — or of opening a multi-card combo (e.g. A and B in a 7-card hand from a 40-card deck).

⚖️ EV & compare

Expected value, swinginess (σ), and a full head-to-head — the whole curve, not just the mean.

🧪 Monte Carlo simulator

For mechanics too messy for closed-form math — run 100k–1M trials. Write a function body with roll("…"), d(n), rng(); return a boolean (win) or a number (value).

// ---- import it ----
gameMath = \{import:game-math-plugin\}

// ---- dice ----
let roll = gameMath.roll("4d6dl1");           // \{ total: 15, rolls: \[4,6,5\], dropped: \[2\] \}
let dist = gameMath.distribution("2d6");
dist.pAtLeast(10);                            // 0.1667
gameMath.distribution("5d6 t4+").pBetween(3, 5);
gameMath.roll("2d6").into("someEl");          // renders dice chips + total

// ---- deck odds ----
gameMath.deck.hyper(40, 4, 7);                // P(exactly k / ≥ k / ≤ k)
gameMath.deck.pDraw(\{deck:40, drawn:7, counts:\[4,4\], need:\[1,1\]\}).p;  // P(A and B)

// ---- EV & compare ----
gameMath.compare("1d12", "2d6");              // \{ pAWin, pTie, pBWin, verdict \}

// ---- monte carlo ----
gameMath.simulate(\{ trials: 200000, seed: 42, each: () =>
  gameMath.roll("2d6rr1").total >= 7 \});
