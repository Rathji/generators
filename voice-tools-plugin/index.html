voice-tools-plugin

Speak anything, out loud. Or listen, and type it for you.

A plugin that gives any generator a full voice toolkit — text-to-speech (voices, queueing, sentence-streaming, live word-by-word callbacks) plus speech-to-text dictation from your microphone. All powered by your browser's built-in speech engine, no servers, no limits.

This browser doesn't support the Web Speech API (speechSynthesis), so the plugin won't be able to speak here. Try Chrome, Edge, Safari or Firefox.

Use it in your generator

// main.pjs — add this line at the top
voiceTools = \{import:voice-tools-plugin\}

// === TEXT → SPEECH ===
await root.voiceTools("Hello world!");

root.voiceTools.speak("Read this next.", \{queue:true\});
root.voiceTools.setVoice("British Lady");
root.voiceTools.settings.rate = 1.2;

// live word-by-word highlighting:
root.voiceTools.speak(text, \{
  onChunk: (\{textChunk, charIndex, text\}) => \{
    // render text with text.slice(0,charIndex) + highlight + ...
  \}
\});
root.voiceTools.stop();

// === SPEECH → TEXT (Chrome, Edge, Safari) ===
const hearing = root.voiceTools.listen(\{
  onInterim: (\{fullText\}) => el.textContent = fullText,  // live partials
  onFinal:   (\{fullText\}) => el.textContent = fullText,  // committed text
\});
hearing.stop();  // stop listening
OptionWhat it does
queue:trueAppend to a queue instead of interrupting (default: interrupt & replace).
voiceVoice name, BCP-47 lang (e.g. "en-US"), voiceURI, object or index. Pick from await tts.voices.
rate / speedSpeaking speed (alias: the original plugin used speed).
pitch / volume / langPer-call overrides of tts.settings.
delaySeconds to wait before speaking starts (default 0).
textStreamA ReadableStream<string> — sentences are spoken as they arrive (e.g. from AI text generation).
onStart / onEnd / onChunk / onErrorCallbacks — also settable globally as tts.onChunk etc.
await tts(...)Resolves with \{text, cancelled, spokenText\} — spokenText is how much was actually read aloud (great for stopping mid-story and resuming).
speak(text).stop()Stops this utterance and returns \{spokenText\}.
listen(opts)Speech-to-text. listen(\{lang, continuous, interim, onStart, onInterim, onFinal, onEnd, onError\}) — resolves with \{text, cancelled\} when stopped, and has a .stop() method. Chrome/Edge/Safari only.
sttSupported / isListeningDictation availability and live listening state.

Long texts are split at sentence boundaries automatically, so even entire books read fine. If a voice ever goes missing, await tts.voices lists everything the browser installed.

Character voices, no API key. The plugin bundles 8 free cloud voices streamed from Google's translate TTS — a British Lady, plus American, Australian, Irish, Indian, South African, Canadian and New Zealand accents. Pick them in the dropdown or with voice:"British Lady". Cloud notes: they need a first user click (autoplay rule), pitch is ignored (rate & volume work), and word-level highlighting becomes sentence-level.

No free service offers a Southern US accent. The closest male voices are the deep US ones built into Windows/Edge (e.g. "Microsoft Christopher" or "Microsoft Guy").

Built on the Web Speech API — works offline, in every major browser, with zero requests to a server.
