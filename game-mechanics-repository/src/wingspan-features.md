# Wingspan — Feature Reference

A system-level reference of Wingspan's features (no content specifics). Useful as a checklist for designing engine-building / tableau card games.

## Core Engine-Building
- Tableau building: play cards into a personal bird board with three habitat rows
- Each habitat row provides a different action when activated
- Cards played into a row add persistent engine abilities
- Engine synergy: actions chain off previously played cards

## Habitats & Actions
- Forest row → gain food action
- Grassland row → lay eggs action
- Wetland row → draw bird cards action
- Each action is enhanced by the birds already in that row (more triggers per activation)
- Action cube / action-track economy (limited activations per round)

## Turn & Round Structure
- Fixed number of rounds (4), each with a set turn count
- Each turn: choose ONE of the four actions (play bird / gain food / lay eggs / draw cards)
- Round goals scored at the end of each round (public, escalating)

## Resources
- Food economy: multiple food types; gained via dice roll in the shared birdfeeder
- Food spent as costs to play birds
- Eggs: currency for both playing birds and scoring; bird egg-capacity limits
- Hand of bird cards (drawn, kept, discarded)

## Bird Cards & Abilities
- Card costs: food type(s) + egg cost
- Ability timing categories: when played, when activated, when another player triggers, end of round, end of game, between turns
- Powers that tuck cards, cache food, draw, or manipulate actions
- Card symbology/icon-driven effects (no text-heavy rules)

## Scoring & Victory
- Layered end-game scoring: points from bird cards, eggs laid, tucked cards, cached food
- Public round goals + secret bonus cards (personal scoring objectives)
- Point salad with multiple strategic paths (food engine, egg engine, card draw engine)

## Player Interaction
- Limited direct interaction (mostly shared food dice, race for goals, race for draftable birds)
- Shared birdfeeder dice pool and shared card draw area
- Turn-order tracking (first-player token rotates)

## Solo & Modes
- Solo automa opponent (automated rival)
- 1–5 players
- Optional expansion layers (additional habitats, new resource types, cooperative play) that extend the base engine

## Presentation & UX
- Well-organized player mats with action tracking
- Icon-driven design enabling silent/pictographic play
