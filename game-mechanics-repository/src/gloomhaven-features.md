# Gloomhaven — Feature Reference

A system-level reference of Gloomhaven's features (no lore/scenario content specifics). Useful as a checklist for designing card-driven cooperative dungeon crawlers / tactical RPGs.

## Card-Driven Action System
- Ability hand per character: each card has a TOP and a BOTTOM action
- Each round you select two cards and perform one top + one bottom action (choice + resource tradeoff)
- Card-initiated initiative values determine turn order each round (revealed simultaneously)
- Card management as a health economy: spent cards are recovered via rest, lost cards are gone until the scenario ends; running out of cards = exhaustion

## Turn & Round Structure
- Simultaneous card selection → reveal → resolve in initiative order → monster turn → rest phase
- Short rest vs. long rest tradeoffs
- Round pacing creates tension between action economy and card longevity

## Tactical Combat
- Hex-grid dungeon maps built from modular tiles
- Move + attack actions; ranged, melee, area/line/AoE attacks
- Attack modifier deck per class (crits, misses, +1s, status riders) — personalized, upgraded over time
- Status effects / crowd control (disarm, stun, immobilize, poison, wound, etc.)
- Traps, obstacles, coins, and interactable dungeon features

## Enemy AI
- Monster ability decks drawn each round (enemy actions vary)
- Focus/priority rules: enemies target based on distance/aggression logic
- Elite vs. normal monster variants
- Summoning and spawn mechanics

## Character Progression
- XP → level ups → new ability cards added to the class pool
- Perks and battle goals (in-scenario objectives that grant advancement)
- Item loadout with limited slots; gold economy and shops
- Card enhancement system (permanent upgrades purchased onto cards)

## Legacy Campaign
- Scenario book with branching campaign structure and prerequisites
- Stickers and permanent board/campaign changes (global & party achievements)
- Character retirement system: personal quests retire a character and unlock NEW classes
- Sealed envelope unlocks revealed over the campaign
- Prosperity, reputation, and persistent town/city progression

## Narrative Events
- City events and road events (narrative decision cards with consequences)
- Reputation and achievements affecting available content

## Modes & Scaling
- 1–4 players with monster difficulty scaling by party level
- Solo-capable design (true solo or multi-hand)
- Deep class asymmetry (each class plays mechanically differently)
