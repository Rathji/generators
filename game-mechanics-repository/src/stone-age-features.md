# Stone Age — Feature Reference

A system-level reference of Stone Age's features (no content specifics). Useful as a checklist for designing worker-placement / resource-management board games.

## Worker Placement Core
- Limited worker pool per player (cavemen); growing your pool is itself an action
- Multiple action spaces on a shared board; workers placed to claim actions
- Placement economics: more workers on a space = better result but opportunity cost elsewhere
- Worker allocation strategy (where to commit limited meeples)

## Action Spaces
- Resource gathering spaces (multiple resource tiers: wood, brick, stone, gold)
- Tool-making (adds to dice results)
- Hunting grounds (variable food yield)
- Fields/farming (passive food income)
- Hut/building construction (point-scoring structures)
- Civilization card space (purchaseable upgrades/scoring)
- Leader/first-player bonus space

## Dice-Resolution Resource Gathering
- Gather action resolved by rolling one die per worker
- Dice results distributed across the resource types by the player
- Tool tokens add fixed bonuses to dice results
- Luck mitigation via tools and worker count

## Food & Feeding Pressure
- Each worker must be fed (food cost) at end of turn
- Food economy: hunting, fields, and food-generating cards
- Starvation penalties create sustained pressure

## Progression & Upgrades
- Civilization cards with escalating effects and end-game scoring multipliers
- Huts/buildings granting points and powers
- Worker breeding (increase pool size over time)
- Tool upgrades

## Turn & Game Structure
- Fixed player-turn loop: place workers → resolve → feed → new turn
- Shared action spaces create blocking/competition
- Game end triggered by deck depletion or round cap

## Scoring
- Layered final scoring: structures, civilization-card multipliers, leftover food/tools/resources
- Early- vs. late-game scoring strategies (short-term resources vs. multiplier engines)

## Player Interaction
- Direct competition for limited action spaces
- Drafting of civilization cards and huts
- Turn-order manipulation via the leader space
- Player count scaling (2–4)
