Connecting your Name.com account allows us to automatically configure and maintain your email security records (DMARC, SPF, DKIM) without you needing to manually edit DNS settings.

Prerequisites:
● Access to your Name.com account.
● Your Name.com Username and Password.

Step 1: Enable API Access (Critical for Two-Factor Authentication)

 If you use Two-Step Verification (2FA) on your Name.com account—which we strongly recommend—you must explicitly allow our system to connect.

1. Log in to your Name.com Account.
2. Click the User Icon in the top right corner and select Settings.
3. Click on Security Settings in the left-hand menu.
4. Scroll to the bottom section labeled Name.com API.
5. Toggle the switch to ON (Green).

○ Why? This setting allows our automated system to securely authenticate using a special token, bypassing the 6-digit code requirement, while keeping your personal login secure.

Step 2: Generate Your API Token

1. On the same Settings page, click API Tokens under the Security section.
2. Click the Create API Token button.
3. Enter a name for the token (e.g., "DMARC Manager").
4. Click Generate new token.
5. Copy the "Production Token" displayed at the top of the screen.

○ Note: You will not be shown this token again. If you lose it, you will need to generate a new one.

Step 3: Connect to Our Platform

1. Return to our dashboard and select Integrations.
2. Choose Name.com.
3. Enter your Name.com Username.
4. Paste the Production API Token you copied in Step 2.
5. Click Connect.

We will verify the connection immediately. If successful, your domains will appear in the dashboard list.
