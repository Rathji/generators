An original message header is often needed to review all the details of the DMARC authentication chain. It can help ensure that everything is functioning properly, as well as identify and fix any potential misconfigurations.
Below is a step-by-step guide on how to locate an email’s full original message header across different mailbox providers:

Gmail

  • Open Gmail in the browser.
  1. Select the email you want to check.
  2. Click the “More” icon (three vertical dots) next to the “Reply” button, then choose “Show original”.
  3. A new window will open displaying the full message header.
  4. Click “Copy to clipboard” or “Download original” to save the header content.





Outlook

  • Log in to your Outlook account in the browser.
  1. Open the email you want to check.
  2. Click on the three horizontal dots.
  3. Locate the “View” option and select “View message source”.
  4. A pop up will appear that contains the original message header.





Yahoo! Mail

  • Sign in to your Yahoo! Mail account in the browser.
  1. Select the email you want to locate the header for.
  2. Click “More” and then “View raw message”.
  3. A new tab will open containing the original message header of the email you selected.


Apple Mail

  • Open Apple Mail.
  1. Select the email for which you want to view the headers.
  2. In the menu bar, click View > Message > All Headers.
  3. A new window will open containing the original message header. 

Zoho Mail

  • Log in to your Zoho Mail account in the browser.
  1. Select the email for which you want to view the headers.
  2. Click on the “Show more actions” button, then “Show original”.
  3. A new tab will appear containing the original message header which you can download as a file or copy to clipboard.
