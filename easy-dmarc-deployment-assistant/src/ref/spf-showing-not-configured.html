In some cases, you may complete the SPF configuration for a specific sending source (for example, Microsoft 365) by adding the provided include mechanism (SPF entry) into the EasySPF dashboard and saving the configuration correctly.

Even after completing these steps, you might notice that the gear icon next to that sending source still shows the SPF status as “Not Configured.”

This behavior is expected.

The SPF and DKIM status shown in the gear icon is based on the data received from DMARC aggregate reports. If the system has not yet received any reports from that specific sending source where SPF checks are passing, the status may still appear as “Not Configured.”

Once EasyDMARC starts receiving aggregate reports from that sending source showing successful SPF authentication, the gear icon status will automatically update to “Configured.”
