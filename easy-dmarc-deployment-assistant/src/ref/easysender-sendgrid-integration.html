The SendGrid Integration allows you to connect your SendGrid account to EasySender and monitor your email activity and deliverability performance directly from one place.

Once connected, EasySender retrieves domain-level data from SendGrid and presents it in a structured dashboard. This helps you track performance, manage your sending domains, and quickly spot potential deliverability issues.

With this integration, you can:

  • Track your SendGrid email sending performance
  • Monitor key deliverability metrics
  • Analyze activity across your domains
  • Manage connected sending domains
  • Identify and address potential issues

1.Accessing the SendGrid Module

  1. Log in to EasySender
  2. Navigate to Admin Console > Integrations
  3. Select SendGrid module from ESP section
  4. Click Connect

2.Creating a New Connection

To connect your SendGrid account, you’ll need to provide your SendGrid API key.

Click Add Connection (or Connect) to open the setup panel.

Required Fields

Connection Name
Enter a name to help you identify this connection (e.g., “Marketing SendGrid” or “Main Account”).

API Key
Paste your SendGrid API key. This is used to securely access your account data.

Important Note:  Make sure your API key has the required permissions to access email activity and domain data.
For more complete insights, ensure your SendGrid account includes extended email activity history (if available on your plan).

3.Credentials Validation

After clicking Next, EasySender will verify your API key.

  • If valid: Your connection is successfully created, and you can proceed to domain selection.
  • If invalid: An error message will appear. Double-check your API key and try again.


4.Domain Selection

EasySender will display the list of domains available in your SendGrid account.

  • Select one or more domains you want to monitor
  • Each domain is shown as a selectable option

If no domains are found:
You’ll see a message indicating that no domains are available. In this case, make sure domains are properly configured in your SendGrid account.

Finalizing the Connection

Once you’ve selected your domains, click Add to complete the setup.

EasySender will:

  • Save your SendGrid connection
  • Add the selected domains for monitoring
  • Redirect you back to the Connections overview
