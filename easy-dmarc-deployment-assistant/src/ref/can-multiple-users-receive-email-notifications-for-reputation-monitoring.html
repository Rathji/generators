When managing Reputation Monitoring, only the account owner who added the IP address or domain will receive email notifications if it gets blacklisted. However, all users within the organisation can view blacklist status updates directly in the Reputation Monitoring dashboard, even if they don’t receive notifications.

If you want specific users to receive email notifications for a blacklisted domain, you can set up alerts. Alerts allow you to specify the email address of the recipient for domain-based notifications. However, please note that alerts can only be set up for domains, not for IP addresses. This ensures that the designated user is informed promptly about blacklist events for the selected domain.
