EasyDMARC has the option of sending source detection for more than 1500 sources.
There are two ways to find the SPF and DKIM setup instructions for a sending source:

1. You can find the SPF and DKIM setup guide for a sending source by clicking on the gear icon next to the source in the aggregate reports. A pop-up window will appear, containing the setup guide links.


2. You can find the sending source configuration guides by searching for them in the EasyDMARC knowledge base or the EasyDMARC Blog.

There might be cases when you search for the sending source in our knowledge base or blog, and there are no results, or you see a flag icon instead of the gear icon next to the source. This might indicate that there is no information about that source in our database. In those cases, feel free to reach out to EasyDMARC technical support.
