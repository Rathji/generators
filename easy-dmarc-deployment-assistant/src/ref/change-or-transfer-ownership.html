You can now transfer the ownership of your Organisation to another User directly from our dashboard. You simply need to follow the below steps to complete the transfer within a few minutes.


1. Go to new User Management page and select the User you want to transfer the Organisation ownership to:

Important: Ownership can only be transferred to a User with the Organisation Admin role. If the current user is not listed, you can invite them easily to your EasyDMARC tenant.





2. Once you select the User and click the Transfer button, you will be presented with a new modal window where you can:
    1. Change the selected User to which the Ownership should be transferred to.
    2. Request and provide a one-time code to validate the request of ownership change.




Important: New Owner or your Organisation cannot own another Organisation at the same time. In case you select such a User, you will be presented with the below notification and prompt to change the User.





3. Request a one-time code, put it into the form and Transfer Ownership button will become available.

 


Afterwards you will receive a notification with confirmation that your role has been updated to Organization Admin and at the same time new Organization Owner will receive a dedicated email with confirmation on changing his role to Organization Owner.
