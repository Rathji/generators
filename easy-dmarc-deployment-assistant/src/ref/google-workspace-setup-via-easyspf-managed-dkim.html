Google Workspace (formerly known as G Suite) is Google’s cloud-based platform that provides productivity and collaboration tools such as Gmail, Google Docs, Sheets, Slides, Calendar, and more. If you're using Google Workspace to send emails, setting up DMARC properly requires configuring both SPF and DKIM first.

SPF (Sender Policy Framework) lets receiving mail servers verify that emails from your domain are coming from authorized servers.

DKIM (DomainKeys Identified Mail) adds a digital signature to each outgoing email, allowing the recipient’s server to verify that the message hasn’t been altered in transit.

In this guide, we’ll walk you through how to set up SPF and DKIM for Google Workspace using EasySPF and Managed DKIM solutions.

How to set up SPF for Google Workspace using EasySPF

1. Navigate to EasySPF and click the “Add source” button


2. Write Google Workspace in the “Source Name” box, after which the system will autofill the SPF mechanism of Google in the relevant boxes.
You can add notes in the “Notes” box if needed. Once done, click the “Add” button.



 Note: Make sure to click the “Save Record” button every time after making any changes in the EasySPF.



How to setup DKIM for Google Workspace using Managed DKIM


1. In the Google Admin Console, open Apps >> Google Workspace >> Gmail >> Authenticate Email

2. By default, your main domain is selected. Click on the primary domain name or select another domain where DKIM will be used.

3. Click “Generate New Record”.  Google Workspace DKIM Public Key will be generated for your domain – copy these values.


4. Navigate to the Managed DKIM in EasyDMARC >> click the “Add Record” button


5. Enter “Google Workspace” in the “Email Sender” box, after which the system will automatically select the record type as TXT and autofill the selector for you.



6. Enter in the “Value” box the DKIM record value copied from Google Admin Console >> Click the “Add” button




Congratulations! You have now set up SPF and DKIM for Google Workspace using the EasySPF and Managed DKIM solutions.
