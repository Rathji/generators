Follow this guide to connect your OVHcloud account, allowing you to manage your DNS records directly from our dashboard. The process involves generating a special set of API keys from your OVHcloud account and adding them to our platform.

Step 1: Begin the API Key Generation

 To simplify the process and ensure the correct permissions are set, we have created a special link that takes you directly to the OVHcloud API key creation page with all the necessary settings pre-configured.

Click on this link to get started

Step 2: Log in to Your OVHcloud Account

 After clicking the link, you will be prompted to log in to your OVHcloud account. Please enter the same username and password you use for the main OVHcloud control panel and click Login.

Note: If your account uses two-factor authentication, you will also need to enter the code from your authenticator app or security key.

Step 3: Configure and Create Your API Keys

You will now be on the "Create API keys" page. Because you used our special link, the correct permissions have already been selected for you. You only need to fill in a few details:

  • Application name: Give the keys a descriptive name you will recognize, such as "EasyDMARC Integration".

  • Application description: (Optional) You can add a more detailed description for your own records

  • Validity: For the integration to work without interruption, select Unlimited from the dropdown menu.

  • Rights: You can leave this section as is. The link has already requested the necessary permissions (GET, PUT, POST, DELETE for /domain/zone/*) to manage your DNS records.

Once you have filled in the details, click the Create keys button at the bottom of the page.

Step 4: Copy Your Three API Keys

This is the most important step. OVHcloud will now display three unique keys. You must copy each one carefully.
● Application Key (AK)
● Application Secret (AS)
● Consumer Key (CK)

CRITICAL WARNING: The Application Secret (AS) is shown only once and will not be retrievable again after you leave this page. Please ensure you copy all three keys and store them securely before proceeding. If you lose the Application Secret, you will need to start this process over again.

Step 5: Enter the Keys into Your Dashboard

Navigate back to the OVHcloud integration page in our dashboard. You will see fields to enter the keys you just copied.

1. Select Your OVHcloud API Region: This is a crucial step. Select the correct region for your OVHcloud account from the dropdown menu (e.g., Europe, Canada, US). If you are unsure, this typically corresponds to the OVHcloud website you use (e.g., ovh.ie for Europe, ovh.ca for Canada).

2. Paste the Application Key (AK): Paste the AK into the "Application Key" field.

3. Paste the Application Secret (AS): Paste the AS into the "Application Secret" field.

4. Paste the Consumer Key (CK): Paste the CK into the "Consumer Key" field.

Step 6: Save and Verify

After pasting all three keys and selecting your region, click the Save or Connect button. Our system will perform a quick check to verify that the credentials are correct.

If the connection is successful, you're all set! You can now manage your OVHcloud DNS records directly from our platform.
If you encounter an error, please double-check that you have copied each key correctly and selected the right API region before trying again.
