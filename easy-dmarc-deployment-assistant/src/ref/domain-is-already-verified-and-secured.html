There might be cases when you want to add a domain to your EasyDMARC account and receive an error message informing you that the domain you want to add is already verified and secured.



This message means that the domain you want to add is already added by another EasyDMARC user and verified. Since the same domain can’t be added by more than one user, the system doesn’t let you add it again.
In such cases, if you know the user who has added the domain, you need to reach out to them so they can remove the domain from their EasyDMARC account, after which you can add it to yours. Or, if you have access to that user’s account, you need to log into that account, remove the domain, and add it to yours.

On the other hand, if you don’t know who has added the domain, feel free to contact EasyDMARC technical support for assistance.
