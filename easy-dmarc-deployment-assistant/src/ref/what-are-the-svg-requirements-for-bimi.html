In order to use BIMI, organizations must first publish a BIMI record in their DNS, which includes the URL of their SVG (Scalable Vector Graphics) logo. The SVG logo must meet the following requirements: The logo must be an SVG file with a .svg file extension. The logo must be square and have a minimum size of 512 pixels x 512 pixels. The logo must be encoded using base64. The logo must not contain any animations or interactive elements. The logo must not use any external resources (e.g., fonts, images, etc.). The logo must not use any proprietary extensions to the SVG standard.
