To enable EasyDMARC to manage DNS records for your email security protocols (DMARC, SPF, etc.) on your GoDaddy-hosted domains, you need to provide us with an API Key and Secret from your GoDaddy account. This is a requirement by GoDaddy to ensure you maintain control over your account access. Follow the steps below to generate these credentials.

Please note that your GoDaddy API Secret will only be shown once during this process, so be sure to copy it immediately.

Caution: If the MSP company has been granted delegated access to their customer's GoDaddy account, please note that generating an API key is not permitted. This restriction is outlined in GoDaddy's terms.

Important: Before you begin, please ensure your GoDaddy account meets the following requirement for API access to manage DNS: your account must have 11 or more domains, OR you must have an active Discount Domain Club – Premier Membership. If your account does not meet this, the API connection may not work.

Steps for API Key Generation:

1. Log In to GoDaddy:
Sign in to your GoDaddy account. 

2. Navigate to Developer Portal: 
Go to the GoDaddy Developer Portal by typing developer.godaddy.com into your web browser's address bar and pressing Enter.

3. Access API Keys: 
Once on the Developer Portal, look for and click on a link or button labeled "API Keys". This might also be found under a "My Account" or similar section if you are already logged in, or directly on a page titled "API Key Management".

4. Create New API Key:
Click on the button to create a new key. This is typically labeled "Create New API Key" or similar.

5. Name Your API Key:  
You will be prompted to give your API key a name. Enter a descriptive name, such as "EasyDMARC Integration" or "EasyDMARC DNS Management". This will help you identify the key's purpose in your GoDaddy account later.

6. Select Environment:
CRITICAL STEP: You will be asked to choose the environment for this API key. It is essential that you select Production (sometimes labeled "Live"). Do NOT select "OTE" or "Test" for the key you will use with EasyDMARC.

7. Save/Generate Key:
Click the "Next" or "Save" button to generate the key.

8. COPY KEY AND SECRET IMMEDIATELY: 
The system will now display your API Key and your API Secret. The API Secret is shown only once and cannot be retrieved again if you navigate away from this page without copying it. Carefully copy both the API Key and the API Secret to a temporary, secure location (like a text file on your computer that you will delete after entering the details into EasyDMARC).

9.Confirm:

Once you have securely copied both the Key and Secret, click "Got it!" or "OK" to close the dialog. 

 

Note: You can configure multiple accounts for every DNS provider we are supporting. The integration page will show an overview of all accounts that are configured with EasyDMARC.

In case of any questions feel free to reach out to EasyDMARC's Support team!
