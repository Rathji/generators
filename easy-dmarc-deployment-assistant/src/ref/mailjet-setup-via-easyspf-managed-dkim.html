Mailjet is a cloud-based email delivery and tracking platform founded in 2010. It enables users to send both marketing and transactional emails with ease.

In this guide, we’ll walk you through how to configure and set up SPF and DKIM for Mailjet using the EasySPF and Managed DKIM solutions.

SPF for Mailjet 

Important Note: Mailjet provides the SPF record, v=spf1 include:spf.mailjet.com ?all, but you should not publish it in your DNS. Instead, only publish the DKIM record. Even if you add the SPF record, Mailjet emails will still fail SPF checks. The correct SPF setup requires a unique CNAME record, which you can find in the end of this article.

How to set up DKIM for Mailjet using the Managed DKIM

1. Head to Account settings from the Mailjet account panel



2. Navigate to Setup SPF/DKIM Authentication


3. Click on the gear icon next to your domain and select Setup SPF/DKIM Authencication, after which Mailjet will provide you with two DNS records unique to your domain.


4. Ignore the SPF record for the reasons mentioned above and copy the value of the DKIM record.


5. Navigate to the Managed DKIM in your EasyDMARC account and click the “Add record” button



6. Enter “Mailjet” in the “Email Sender” box, after which the system will automatically select the record type as TXT and autofill the selector for you.




7. Input in the “Value” box the DKIM record value copied from the Mailjet and click the “Add” button



Once verified, you’ll be able to see Mailjet displaying your DomainKey record looks good!



Congratulations! You have now set up DKIM for Mailjet using the Managed DKIM solution.
