The Event Logs module will guide you in understanding sending behaviour, diagnosing issues and validating delivery outcomes.

The Event Logs module includes:

Event tracking & Centralised Visibility: A comprehensive logging interface that captures all significant email lifecycle events—such as Sent, Delivered, Bounced, Opened, Clicked, Unsubscribed, and Complained—offering a cohesive timeline of system activities. This structured event data representation enables you to easily comprehend what actions took place, when they occurred, and which entities (domains, email addresses, sources) were involved. 

Export Functionality: The ability to export data in CSV format, enabling you to retrieve event information according to their current filters for offline analysis and reporting.

Toolbar: 

  • Search field
  • Date Picker
  • Filter

Now let’s dive into each section for better understanding.

The Toolbar section contains the “Search” field, “Select Date Range” to modify the timeframe and “Export CSV” option to download the data of the selected date range.

The "Filter" field provides a powerful tool that allows you to set custom criteria to display only the data you need:

In the tabular layout you can find the following columns: Timestamp, Sending Source, Message ID, Event, Domain, From Email, Recipient Email, Delivery Status Message.

You can rearrange the timestamps using the "arrow" icon, which allows you to view either the most recent data (default visibility) or the sequence starting from the initial entries: 

In the following columns you will find details such as the Sending Source name, Message ID, Event (Sent, Delivered, Bounced, Opened, Clicked, Unsubscribed, Complained), the Domain of the From email, as well as Recipient email and Delivery status (for delivered and bounced events only).


Upon clicking on one of the entries you can find further details like the Event IP and the Region specification in case of Amazon SES.
