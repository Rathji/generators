Yes, subdomains inherit the BIMI record from the organizational domain by default unless a separate BIMI record is published for the subdomain.


For example:

  • If you publish a BIMI record at example.com, subdomains like no-reply.example.com or support.example.com will automatically use the same BIMI logo.
  • If you want a subdomain to display a different logo, you can create a specific BIMI record for that subdomain.

For more information, and Managed BIMI configuration, refer to this article!
