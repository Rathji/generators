To allow us to manage your SPF, DKIM, and DMARC records automatically, you need to generate a set of API credentials from your EasyDNS control panel.

Prerequisites:

● You must have an EasyDNS account.

● Your domain must be using EasyDNS name servers.

● Important: The API Key is only displayed once. Please keep the tab open until you have pasted the key into our dashboard.

Step-by-Step Instructions:

1. Log in to your (https://cp.easydns.com/).

2. In the top navigation menu, go to User > Security.

3. Scroll down to the section labeled REST API.

            ○ Note: If you do not see this section, you may need to request API access from EasyDNS support, though it is standard on most active accounts.

4. In the REST API section click Info for the Production option.

5. Click the New Token (or use the existing one) button.

6. Name your Token, choose context as Global or Domain and click Create.

            ○ Leave “Read Only?” checkbox unchecked

7. Copy newly created Token and API Key
            ○ Token: (This acts as your username).
            ○ API Key: (This acts as your password).

8. Return to our dashboard and paste the Token and API Key into the respective fields.
