Help Scout’s shared inbox, help center, and live chat software gives your team the tools you need to easily manage customer communications.

SPF Configuration

Help Scout doesn’t support SPF alignment, so there is no need to add the mechanism of the source to your SPF record. Emails sent from Help Scout servers will now pass SPF validation using a variable envelope return path (VERP) address set to their servers.

DKIM Configuration

To configure DKIM for Help Scout, you need to add two CNAME records to your DNS hosting provider (DNS zone). These records allow recipient mail servers to retrieve the DKIM public key from Help Scout, enabling proper authentication of your outgoing emails.

Required CNAME Records

Add the following CNAME records to your domain:

strong1._domainkey.yourdomain.com will point to strong1._domainkey.helpscout.net

  • strong2._domainkey.yourdomain.com will point to strong2._domainkey.helpscout.net

How to Obtain the CNAME Records from Help Scout

  1. Log in to your Help Scout account.
  2. Navigate to Manage → Inboxes.
  3. Select the inbox you want to configure.
  4. Go to Outgoing Email → Use Help Scout.
  5. The system will provide the two required CNAME records.

  6. Copy these records and add them to your DNS zone.

Important Notes

  • If you are using Cloudflare, make sure the Proxy status is turned off (DNS Only) for both CNAME records.
  • DNS changes may take some time to propagate across the internet.

Verify DKIM Configuration

After adding the records and allowing time for DNS propagation:

  1. Return to the Help Scout dashboard.
  2. Click the Test Settings button located in the lower-left section.
  3. If the CNAME records are detected correctly, the DKIM status will change to Active.

That’s it!. You’ve successfully authenticated your outgoing mail stream from Help Scout using DKIM. This helps improve email security and reduces the likelihood of your messages being marked as spam.
