EasyDMARC provides public APIs designed to serve three distinct audiences: EasyDMARC customers, EasyDMARC partners, and developers.
API access is achieved by submitting HTTPS requests to a specific version endpoint URL, utilizing the GET, POST, PUT, PATCH, and DELETE methods to govern interaction with the available information. All endpoints are exclusively accessed via the SSL-enabled HTTPS protocol (port 443).

Here is how you can locate the EasyDMARC public APIs:

1. Navigate to the “Admin Console” section:


2. From the sidebar, find the “Public API” and click on the section name.

Note: In case you don’t have access to the APIs, you will be redirected to a page which will instruct you to contact sales.

 

In this case, you need to first contact the EasyDMARC sales team so they can enable API access for your account.

Once you have access to the APIs, you will be presented with the option to generate a key, as it’s shown in the screenshot below.

 


To check the EasyDMARC Public API documentation, click the “Generate Key” button, after which a pop-up window will appear containing the link to the Public API documentation:




The Public API documentation details the accessible endpoints, necessary parameters, and illustrative examples for utilizing each function.


In case you have any additional questions, feel free to contact EasyDMARC technical support.
