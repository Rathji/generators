Notes

  • uploads.dev is Perchance's own file host — no account or key, permanent direct URL, and it's the only host here that needs no setup at all. Use it, or GitHub / Neocities / Codeberg, for images, scripts or data files in your Perchance generators (those three need an account — a fine-grained token, an API key, or a write:repository token respectively).
  • tmpfiles.org files are deleted automatically after the retention you pick (60 min – 48 h); the site currently caps files at ~100 MB. gofile.io guest uploads are free, up to ~20 GB, kept 10 days after the last download. Litterbox (by the catbox team) deletes after 1–72 h and allows up to 1 GB.
  • The quick-share uploads go through the superFetch plugin so they work from any origin; uploads.dev uses the official upload-plugin, and GitHub/Codeberg calls hit their APIs directly (CORS-enabled) so your token never passes through a third-party server.
