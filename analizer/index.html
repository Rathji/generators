How it works

1

Fetch & snapshot

Enter a generator name and fetch its full source — main.pjs, index.html and every transitive import. Save snapshots to kv to keep a history of versions.

2

Diff versions

Compare a saved snapshot against a fresh fetch: line-level diff hunks, structural changes (lists, functions, configs), and a readable summary of new features and potential breaking changes.

3

Query & analyze

Ask the AI how any part of the implementation works — it cites the exact file and line ranges — or generate a full architectural overview, feature inventory and dependency tree.

Notes

  • Snapshots are stored per-user in the kv plugin (IndexedDB) — they persist across reloads but aren't shared between users.
  • Fetching uses getGeneratorsAndDependencies for main.pjs + imports and getGeneratorHtml for index.html; all requests go through superFetch so no CORS issues.
  • Query and analysis answers are streamed from the ai-text-plugin — the AI cites the exact chunk / file and line ranges used.
  • Reports can be exported as .md, .txt, or structured .json (diff JSON includes the raw hunks).
  • Settings accept URL overrides: ?theme=light&accent=%23ec4899&size=18&motion=true.
  • Built on rathji-template — badge, card, settings panel, toasts and shareable state are all copyable patterns.
  • More generators by Rathji: perchance.org/rathjis-generators
