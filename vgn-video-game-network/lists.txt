//
//  To ADD a game: copy one `game` block and fill it in.
//    slug        → REQUIRED. The part of the URL after
//                  perchance.org/  Network originals use the
//                  `vgn-` prefix (e.g. "vgn-pong"); classic
//                  tribute cards use their plain name.
//    title       → Name shown on the cabinet.
//    era         → Era chip + filter: Arcade | 8-Bit | 16-Bit |
//                  Early 3D | Network
//    year        → Release year, shown on the cabinet ("TBD" ok).
//    genre       → Genre chip, used by search.
//    blurb       → One-line description under the title.
//    players     → OPTIONAL. e.g. "2 players".
//    color       → OPTIONAL. Accent color for the card.
//    icon        → OPTIONAL. Glyph used in the marquee.
//    image       → OPTIONAL. Cover art URL. Leave blank for a
//                  generated gradient cover.
//    comingSoon  → `comingSoon = true` marks a cabinet as
//                  COMING SOON (not linked yet). OMIT the field
//                  entirely for a live game — its card then
//                  links straight to the slug and shows PLAY NOW.
//
//  NOTE: era = Network games are our own planned originals. The
//  rest are classic/retro tributes — all marked coming soon until
//  a live page exists for each one.
// ─────────────────────────────────────────────────────────────
