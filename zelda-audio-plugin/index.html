    How to use it in your own generator

    // 1. In main.pjs, add the import:
zeldaAudio = \{import:zelda-audio\}

// 2. Then use it from your code:
root.zeldaAudio.play("boss");              // random boss battle (any game)
root.zeldaAudio.play("song of time");      // search by name (or album)
root.zeldaAudio.playShuffle("orchestral"); // shuffle the whole orchestra
root.zeldaAudio.playShuffle("twilight symphony"); // one album
root.zeldaAudio.playShuffle("");           // shuffle everything (429 tracks)
root.zeldaAudio.setVolume(0.4);            // 0..1
root.zeldaAudio.loop(true);
root.zeldaAudio.crossfade(1200);           // smooth 1.2s crossfades
root.zeldaAudio.stop();

// Every track has: \{track, name, cat, game, url, length\}
// Orchestral tracks also carry: album, albumSlug, era
// Games: "oot" | "lttp" | "orchestral" — filter with find(game)
// Albums: root.zeldaAudio.albums (21 albums, counts, eras)
// Favorites: root.zeldaAudio.toggleFavorite(url) / favorites()
