Password rules

Fine control over every character

Each option is applied before the password is built, so the output always matches your policy exactly.

Character classes

Toggle uppercase, lowercase, digits and symbols independently. Disabled classes never appear in the output.

Exact length

Set a precise length from 8 to 64 characters. Every generated password matches it exactly — no more, no less.

Readability filters

Exclude look-alike characters (0 O 1 l I) and guarantee every selected class appears at least once.

Uniqueness & readability

Force no repeating characters, or switch to pronounceable mode for phonetic, human-friendly passwords.

Passphrase mode

Combine words from Common English, Technical or Random dictionaries with a separator, per-word case, and digit/symbol injection.

Entropy & strength

Every result reports its entropy in bits with a color-coded strength meter, so you can audit how strong each password is at a glance.

Passwords are generated with crypto.getRandomValues — the same CSPRNG the browser uses for TLS keys. Entropy is reported in bits so you can audit strength.

Passphrases join 3–12 words from a chosen dictionary (Common English, Technical or Random) with a separator of your choice. You can capitalize words and inject digits or symbols at the start, end, or between words.
