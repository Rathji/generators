Nucleus Guide

How this template works

  1. ⚡ Auto-Build does everything: random prompt → AI enhancement → render.
  2. Or go manual: 🎲 for a random prompt → ✨ to enhance → Render.
  3. Renders come out 2 at a time. ＋ Add 2 More grows the grid; ↻ on any card re-rolls just that image.
  4. Click any image to view it large and save it. 📋 copies your prompt + last seed.
  5. Press Ctrl+Enter to render fast. If the image service stalls, a ↻ Retry button appears.
  6. Every render is auto-saved to your Vault (🗃) — reopen, re-render, export, or delete anytime.
  7. The 🖼 Gallery is the public community gallery for this generator.
  8. Gear icon (top-right) → theme, accent color, text size, reduced motion. All saved locally.
  9. Press R for a random prompt and Esc to close any dialog.
  10. 💬 Chat mode: pick a persona chip, type, and hit Enter — replies stream in. Hover a message for copy / edit-and-resend / regenerate / delete.
  11. Use imagine: a wizard tower to generate an image right in the chat; use 📎 to attach an image and ask the AI about it.
  12. Chat AI settings (gear) → temperature + style; every conversation is saved locally in ☰ Chats.
  13. 🔗 Share copies a link containing this chat — anyone who opens it sees the conversation.
  14. ☰ Chats → ⬇ Export / ⬆ Import downloads or restores all conversations as a JSON file.
  15. 🔍 searches this chat's messages (↑/↓ jump between matches); the pill in the header shows context usage, and long chats auto-summarize.
  16. Fresh chats show starter chips above the input — tap one to begin.
  17. Slash commands (type in the box): /help · /clear · /new · /persona name · /save title · /imagine … · /search … · /export · /share.
  18. Keyboard: Enter sends (Shift+Enter = new line), ↑/↓ recall past messages, / jumps to the box, Alt+R re-rolls the last reply, Alt+F opens search.
