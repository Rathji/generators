Capture a Perchance generator's theme — or turn any web page into clean Markdown.

How to use Extrax

Theme Capture

  • Type a Perchance generator name (e.g. cozy-forest-quest) or paste its URL, then hit Capture theme.
  • Tick also make a mood image to generate an atmospheric image for the card (slower; uses the image plugin).
  • Each captured theme is saved to your vault with Copy theme, Copy CSS (a ready-to-paste @import + :root + body snippet), a per-card Mood image button, editable notes, and Delete (click twice to confirm).
  • Use the search box above the grid to filter by title, theme, fonts, tags or notes, and Export JSON / Export Markdown / Import… to back up or move your vault.

Web → Markdown

  • Choose Single page to convert one URL, Batch to paste many URLs (one per line), or Site crawl to follow links from a start page across a whole site.
  • In Site crawl, set a depth and max pages, optionally restrict to the same host or to URLs containing a path (e.g. /docs/), then crawl. Every page becomes its own .md; Download .zip packs them into folders that mirror the site's URL paths, alongside a _index.md listing.
  • Set the shared options first: include Images and Front-matter, pick how Links are written (absolute / relative / footnotes), and choose a Size cap for very large pages.
  • After a capture, review the Markdown preview, then Download .md, Copy Markdown, or Save to library.
  • The AI cleanup box scores how messy the extraction is; pick a style (or write a custom instruction) and hit Clean up with AI. Compare the revision, then Use this version, Discard, or Refine again with feedback. Revision chips let you jump back to the Original at any time — nothing changes until you accept it.
  • In Batch mode each row can be Retried, Cleaned, copied, downloaded or saved on its own, or Removed to drop that page from the run. Save all exports every kept page — as one combined file, or one file per page with Individual files ticked — in Markdown or JSON.
  • Site crawl rows have the same Remove action and shared Save all control: drop any page and the zip, index and exports update to match.
  • The documents library below is searchable and taggable, with per-document notes and Copy / Download / Delete. Use Export JSON for a lossless backup or Export Markdown for a readable, re-importable reference.
Privacy: your themes and documents are saved only in this browser (Perchance's local kv store) — nothing is uploaded to Extrax. Web pages are fetched through Perchance's super-fetch proxy, and the optional AI cleanup sends the extracted Markdown to the text-generation plugin to be rewritten. Pages behind a login, a paywall or anti-bot protection can't be captured, and very large pages are truncated at the size cap you select.
