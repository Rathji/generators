3 · Deck Builder — search & edit

The builder edits a live copy of the deck. "Sync → Input" writes it back to the input textarea so it can be re-exported / re-checked. New cards added here start with no set code — use "Auto-fill sets" then "Check online" for a clean legality pass.

4 · Tips & Docs

  • Import: paste text from Arena, Moxfield, Archidekt or TappedOut (handles Deck:, Sideboard:, // Sideboard, + 2x Card, card counts, and (SET) codes). Paste a raw MTGJSON deck object and it’s parsed automatically.
  • Export: MTGJSON JSON, Arena text, or a plain list for Moxfield/Archidekt.
  • Builder: search Scryfall, add copies to main or side, adjust counts, and get a suggested manabase for your colors.
  • Live checks (legality + stats) hit api.scryfall.com and are always current; Frontier uses a built-in snapshot.
  • Share encodes the deck into the URL hash; Open file reads .txt or .json.
