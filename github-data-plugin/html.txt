<div class="wrap">
  <h1>🐙 <span class="grad">github-data-plugin</span></h1>
  <p class="tagline">Fetch data from any public GitHub repository — files, JSON, repo info, and file listings — right inside your Perchance generator.</p>

  <h2>Import</h2>
  <p>Add this line to the top of your lists editor:</p>
  <pre><code>gh = \{import:github-data-plugin\}</code></pre>

  <h2>Basic usage</h2>
  <p>Fetch a file's text from a repo (the default branch is auto-detected):</p>
  <pre><code>let readme = await root.gh("octocat/Hello-World", "README");
outputEl.textContent = readme.text;</code></pre>
  <p>Fetch and parse a JSON file:</p>
  <pre><code>let pkg = await root.gh("microsoft/vscode", "package.json", \{format:"json"\});
outputEl.textContent = pkg.data.name;</code></pre>
  <p>Get repo info:</p>
  <pre><code>let info = await root.gh("octocat/Hello-World");
outputEl.textContent = info.data.stargazers_count + " stars";</code></pre>
  <p>List a directory, or get every file path in the repo:</p>
  <pre><code>let files = await root.gh("octocat/Hello-World", "src", \{format:"list"\});
let allPaths = await root.gh("octocat/Hello-World", null, \{format:"tree"\});</code></pre>

  <h2>Render straight into an element</h2>
  <p>No <code>await</code> needed — the plugin shows a "Loading…" state and fills the element in:</p>
  <pre><code>root.gh.into("outputEl", "octocat/Hello-World", "README");
root.gh.into("outputEl", "microsoft/vscode", "package.json", \{format:"json"\});</code></pre>

  <h2>Push &amp; backup</h2>
  <p>Push files to any repo you have write access to — GitHub's Git Data API is used, so all files in one call land in a <b>single commit</b>. Great for backing up this generator, or storing a reference template.</p>
  <div class="warn">🔑 <b>Your token, your browser.</b> Pushing needs a GitHub Personal Access Token. Use a <b>fine-grained token</b> scoped to just the target repo, with <b>Contents: Read and write</b>, and an expiry date. It is stored only in your browser's localStorage and sent only to <code>api.github.com</code> — never hardcode it, and never paste it anywhere public (this plugin's source is visible to everyone). Anyone who obtains your token can write to your repos.</div>

  <pre><code>root.gh.setToken("github_pat_...");   // once per browser (localStorage)

// push several files in one commit:
let r = await root.gh.push("owner/repo", \{
  "main.pjs": "...", "index.html": "..."
\});
// r = \{ ok, branch, commitSha, files, message, url \}

// or a single file:
await root.gh.pushFile("owner/repo", "src/data.json", "...");

// back up THIS generator (pushes its main.pjs + index.html):
let r2 = await root.gh.backupGenerator("owner/repo");</code></pre>

  <h2>API reference</h2>
  <table>
    <tr><th>Call</th><th>Returns</th></tr>
    <tr><td><code>gh(repo)</code></td><td>Repo info object (in <code>.data</code>)</td></tr>
    <tr><td><code>gh(repo, path)</code></td><td>Raw file text</td></tr>
    <tr><td><code>gh(repo, path, \{format:"json"\})</code></td><td>Parsed JSON object</td></tr>
    <tr><td><code>gh(repo, path, \{format:"list"\})</code></td><td>Array of directory entries</td></tr>
    <tr><td><code>gh(repo, null, \{format:"tree"\})</code></td><td>Array of all file paths</td></tr>
    <tr><td><code>gh.raw(repo, path)</code></td><td>File text (throws on error)</td></tr>
    <tr><td><code>gh.json(repo, path)</code></td><td>Parsed JSON (throws on error)</td></tr>
    <tr><td><code>gh.info(repo)</code></td><td>Repo info object (throws on error)</td></tr>
    <tr><td><code>gh.list(repo, path)</code></td><td>Directory entries array (throws)</td></tr>
    <tr><td><code>gh.tree(repo, branch)</code></td><td>File path array (throws)</td></tr>
    <tr><td><code>gh.fetch(url)</code></td><td>Raw fetch Response passthrough</td></tr>
    <tr><td><code>gh.into(el, ...)</code></td><td>Renders the result into an element (by id or element)</td></tr>
    <tr><td><code>gh.setToken(t)</code></td><td>Save your GitHub token in this browser's localStorage</td></tr>
    <tr><td><code>gh.getToken()</code> / <code>gh.clearToken()</code></td><td>Read / clear the saved token</td></tr>
    <tr><td><code>gh.push(repo, files, opts)</code></td><td>Push an object/array of files in one commit (throws on error)</td></tr>
    <tr><td><code>gh.pushFile(repo, path, content, opts)</code></td><td>Push a single file (throws on error)</td></tr>
    <tr><td><code>gh.backupGenerator(repo, opts)</code></td><td>Push this generator's main.pjs + index.html (throws on error)</td></tr>
  </table>
  <p class="note">The main <code>gh(...)</code> call never throws — on failure it resolves to a String object with <code>.error</code> set and <code>.ok === false</code>. The <code>gh.raw/json/info/list/tree</code> helpers throw instead, so you can use <code>try/catch</code>.</p>

  <h2>Options</h2>
  <pre><code>\{ path, branch, format \}   // branch: default is main → master → HEAD
// format: "text" | "json" | "info" | "list" | "tree"</code></pre>

  <h2>Notes</h2>
  <ul>
    <li>Uses GitHub's public APIs — <b>no token needed</b>. <code>api.github.com</code> allows ~60 unauthenticated requests/hour per IP; <code>raw.githubusercontent.com</code> is effectively unlimited.</li>
    <li>All requests are plain CORS-enabled <code>fetch()</code> calls — works in any Perchance generator without super-fetch.</li>
    <li>Because of that rate limit, prefer the raw fetch (plain text / JSON files) for data your generator loads on every page view, and use the API calls for one-off actions.</li>
  </ul>

<script>
  function ghDemo(args) {
    var el = document.getElementById("demoOut");
    window.__ghDataPlugin7483621.into(el, args[0], args[1], args[2]);
  }
  function setOut(text) {
    document.getElementById("pushOut").textContent = text;
  }
  function ghSaveToken() {
    var t = document.getElementById("tokIn").value.trim();
    window.__ghDataPlugin7483621.setToken(t);
    setOut(t ? "Token saved in this browser ✓" : "Token cleared");
  }
  function ghClearToken() {
    window.__ghDataPlugin7483621.clearToken();
    document.getElementById("tokIn").value = "";
    setOut("Token cleared");
  }
  async function ghBackup() {
    var repo = document.getElementById("repoIn").value.trim();
    if (!repo) { setOut("✗ Enter an owner/repo first."); return; }
    setOut("Backing up this generator…");
    try {
      var r = await window.__ghDataPlugin7483621.backupGenerator(repo);
      setOut("✓ " + r.files.join(", ") + " → " + r.url);
    } catch (e) { setOut("✗ " + (e && e.message || e)); }
  }
  async function ghPushFile() {
    var repo = document.getElementById("repoIn").value.trim();
    var path = document.getElementById("pushPath").value.trim();
    var content = document.getElementById("pushContent").value;
    if (!repo || !path) { setOut("✗ Enter an owner/repo and a file path."); return; }
    setOut("Pushing " + path + "…");
    try {
      var r = await window.__ghDataPlugin7483621.pushFile(repo, path, content);
      setOut("✓ " + path + " → " + r.url);
    } catch (e) { setOut("✗ " + (e && e.message || e)); }
  }
</script>
