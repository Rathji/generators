🎲 D20 Tabletop Plugin

A Perchance tabletop RPG rules framework as a plugin: a single importable $output in front of a modular, D&D-style rules engine. Structure from rathji-plugin-template / card-deck-plugin, conventions from Rathji's Plugin Tutorials — one roadmap task at a time.

What this is

A Perchance plugin is just a normal generator written to be reused. The one special thing is the $output function at the bottom of main.pjs — when another generator imports this one, the name on the left of the import line becomes that function. The lists, data and helpers below it are all ordinary Perchance code.

This page doubles as the plugin's docs and a live test harness — every claim below is exercised by the demo at the bottom.

How the template is structured

main.pjs is organised into four sections. Each one is a pattern lifted from a real plugin, with a TODO marking where your code goes:

SectionWhat it's forSeen in
$metaTitle, description and tags — shown on your listing pageboth plugins
Imports — simpleGenFooterBind other generators' $output to names; the standard Perchance footertutorial steps 1–3
Embedded data — initD20TabletopData()One lazy-initialised bundle for big payloads (svg templates, word lists, base64 assets). Created once, on first usecard-deck-plugin
Lists — d20TabletopPresetsReusable preset values; users can pass these as argumentstutorial step 4
Helpers — d20TabletopStamp()The real logic, kept out of $output so it stays thin and testablecard-deck-plugin
$output(...)The plugin entry point — this is what importers receivetutorial step 6

Make it yours

  • Rename. Replace d20Tabletop / d20Tabletop* function names in main.pjs with your plugin's name.
  • Describe. Update the $meta title, description and tags.
  • Write the logic. Add helpers in section 3 and call them from $output. It should return a string (usually HTML) or a Promise.
  • Trim. Delete section 1 (embedded data) and the d20TabletopDefaults() helper if you don't need a payload.
  • Stay robust. Never throw — return a readable (...) placeholder on bad input, like the template's $output does.
  • Publish. Save this generator, then import it from anywhere using the standard import syntax — see the Import section above.

Notes

  • The template never throws — bad input returns (d20Tabletop: expected some text — …) instead of an exception.
  • Arguments support plain values and Perchance lists alike (every pjs value is a node, read through evaluateItem).
  • This page is the demo/test harness — the live demo calls the template's own $output to prove every documented call works.
