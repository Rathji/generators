How it works
Perchance's image API supports reference-image editing (img2img) but not true latent-mask inpainting, so this tool fills the painted region with noise, regenerates it via image-to-image, then composites the original pixels back everywhere you didn't paint. For best results: work on photographs, paint tightly around a small-to-medium target, and use two-pass mode for clean object removal. "Use as new image" chains edits together.
