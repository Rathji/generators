Catalogue

Every type, one spec

The list below is read live from charts.types — a machine-readable catalogue of every chart this plugin can render, grouped by what the chart is for. Any of them is reachable three ways: as a method (charts.stackedBar(data)), by catalogue id through charts.render, or as a type hint to charts.infer.

Playground

Try it with your own data

Paste any data shape below, pick a chart type (or auto, or the spec-driven render), hit render. Invalid data returns a friendly placeholder instead of crashing.

💡 Hint: auto is what you get from charts.infer(data) — it picks a sensible chart and honours an explicit type hint. Every catalogue id works the same way: charts.types lists them, charts.typeMeta(id) names the method.

Options

Reference

Data formats

The same data shapes work for every chart type (pie/donut/histogram just use the first series). Scatter takes x/y pairs and heatmap takes a matrix of numbers, so those two have shapes of their own — shown below.

Rasterise

Export any chart as a PNG

SVG is perfect on a page, but embeds, PDF/Word exports and sharing want pixels. charts.png(svgOrSpec) rasterises anything the plugin renders — pass an SVG string or a spec object — and gives you a Blob, with pngBytes / pngDataUrl for the byte and data-URL flavours. This is the one browser-only, async part; everything else is a pure string.
