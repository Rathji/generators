Playground

Try it with your own data

Paste any data shape below, pick a chart type (or auto), hit render. Invalid data returns a friendly placeholder instead of crashing.

💡 Hint: the auto type is what you get when you call charts.infer(data) — it picks a sensible chart for your data, and honours an explicit type option as well.
