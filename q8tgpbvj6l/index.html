🔑 Token is stored only in this browser (localStorage) and sent only to api.github.com. Never paste it anywhere public — this generator's source is visible to everyone. Create one at github.com/settings/personal-access-tokens.

2

Backup → GitHub

Pushes this generator's last-saved main.pjs + index.html to the <generatorName>/ folder in the repo as a single commit.

3

Restore ← GitHub

Fetches main.pjs + index.html from the <generatorName>/ folder so you can review or download them.
