🎲 3d-dice-plugin

Generate beautiful SVG dice (d2–d20, pips & numerals, any colour) and roll them — standard dice notation, keep/drop & advantage, animated roller UI.

Live roller

This is the full embeddable widget, running the plugin itself. Click a die below the tray to add it, click a die in the tray to remove it, or type a formula like 2d6+1d4+3, 4d6kh3 or 2d20dis, then press Enter or Roll.

One-shot animated roll

dice.throw(formula, el) rolls once, animates the dice into place, and returns the result immediately (the total is available before the animation finishes).

Generated faces

Every die is generated as a flat, dead-on SVG "face plate" — the same rendering as the Die face plates generator. Faces are now cropped flush to the die shape (no canvas margin), so they map straight onto a 3D die; pass tight:false to get the full plate with its studio backdrop. Pip faces on square dice, numerals elsewhere, with a full acrylic palette derived from one base colour.

Notes

  • Everything lives in main.pjs — importing the plugin gives you the whole API, no extra files to host.
  • The face renderer is the "Die face plates" approach by Rathji (bgn-dice-generator), vendored into this plugin — including the tight/cropped export style it now produces.
  • The 3D physics roller is an original vanilla three.js + cannon-es implementation (MIT libs loaded from esm.sh at runtime), inspired by react-3d-dice by aqandrew — which ships without a license (all rights reserved), so this is a from-scratch rewrite, not a licensed derivative. The D10 geometry is adapted from that project. The approach traces the same lineage its README credits: Anton Natarov's dice roller (public domain) and Michael Wolf's remix.
  • Rolling uses Math.random() like the rest of Perchance — wrap/replace it if you need seeded rolls.
