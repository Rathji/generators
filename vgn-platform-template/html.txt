<!--
  VGN Platform Game Template — a ready-to-fork platformer template for the
  Video Game Network (slug: vgn-platform-template).

  Code lives in src/: 00-core.js (loop, input, physics, camera, HUD),
  10-level.js (the example level's tile map + spawn data), 20-tiles.js
  (rendering, tile art, backdrop parallax, animations), 30-player.js (the
  player character), 40-actors.js (enemies, items, block strikes),
  50-audio.js (WebAudio SFX and the level-clear sequence). They are plain
  classic scripts loaded in filename order — the order is load-bearing, so
  keep the numeric prefixes. Edit the src/ files directly; there is no
  build step.

  Everything renders with procedurally generated pixel art and synthesized
  sound: no images, no sprite sheets, no audio files, no fonts, no CDN.

  To make it your own game: tune the movement constants at the top of
  30-player.js, redraw the tile map in 10-level.js (one char per tile), and
  edit the sprite grids in 30-player.js / 40-actors.js. The example level
  shows off every mechanic the engine supports.
-->
