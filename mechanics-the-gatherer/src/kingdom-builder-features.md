# Kingdom Builder — Feature Reference

A system-level reference of Kingdom Builder's features (no content specifics). Useful as a checklist for designing abstract placement games with variable scoring.

## Abstract Placement Core
- Players place settlements on a modular hex board
- Placement is constrained by terrain and adjacency rules
- No combat — pure spatial competition

## Terrain & Location Cards
- Each turn a terrain card dictates where you may build
- Special locations (castles, oases, etc.) trigger unique effects
- Placement freedom is limited by the drawn card

## Action Tokens
- Building near certain locations grants action tokens
- Tokens perform special actions (move, build, draw, etc.)
- Action economy interacts with placement choices

## Variable Scoring Objectives
- Each game draws three scoring cards from a set
- Objectives range (e.g. most settlements in regions, longest lines)
- The scoring mix changes strategy every game

## Board Modularity
- Four board quadrants combine into many layouts
- Board variety plus objective variety drive replayability
- Scales 2–4 players

## Endgame
- The game ends when the terrain card deck runs out
- Players score against all three objectives; highest total wins
- Turns are quick; the whole game is spatial optimization
