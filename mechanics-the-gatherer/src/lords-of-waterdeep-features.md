# Lords of Waterdeep — Feature Reference

A system-level reference of Lords of Waterdeep's features (no content specifics). Useful as a checklist for designing worker-placement / quest-management board games.

## Worker Placement Core
- Limited agent (worker) pool per player; agents are the action currency
- Shared board of action spaces in the city; placing an agent claims that space's action for the turn
- Agents return at the start of each new round (fresh allocation each round)
- Blocking/competition: spaces hold limited slots, driving turn-order and timing decisions

## Action Spaces
- Adventurer recruitment spaces (multiple adventurer types as a resource)
- Gold-gain spaces
- Quest card draw spaces
- Intrigue card draw spaces
- Building construction spaces (build and place new buildings)
- Turn-order/first-player spaces

## Quest System
- Quests are completed by paying adventurer-type + gold costs
- Quest rewards: victory points plus bonuses (resources, extra actions, points for others)
- Plot quests: provide ongoing/per-turn abilities once completed
- Mandatory quests ("the pie"): forced-quest mechanic that pressures players and adds chaos
- Quest variety drives divergent strategies

## Intrigue Cards
- Hand of intrigue cards with effect-driven play (gains, sabotage, theft, forced effects on other players)
- Player interaction without direct negotiation
- Attacks can target other players' agents or quest progress

## Buildings & Shared Economy
- Players purchase buildings; purchased buildings become permanent action spaces usable by ANY player
- Building owner earns a reward whenever others use their building (passive income / point engine)
- Expanding the board = expanding available actions over the game

## Hidden Objectives
- Secret Lord identity: each player has a hidden end-game bonus tied to certain quest types
- Hidden scoring adds a deduction/guess layer to the competition

## Turn & Game Structure
- Fixed number of rounds (round track), agents refresh each round
- End-game trigger: rounds exhausted → final scoring
- First-player/turn-order dynamics with action-space scarcity

## Scoring & Victory
- Victory points from completed quests, building usage, and hidden Lord bonuses
- Short-term VP vs. long-term engine tradeoffs

## Modes & Expansion Layers (optional)
- Base 2–5 players
- Common expansion modules add corruption, skulls, and additional board modules
