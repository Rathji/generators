# EXIT: The Game – The Deserted Lighthouse — Feature Reference

A system-level reference of EXIT: The Game (puzzle/escape-room format). Useful as a checklist for designing cooperative one-shot puzzle games with progressive hint systems.

## Cooperative Puzzle Structure
- Players work as a team against the game rather than each other
- Fixed session goal: escape the scenario (lighthouse) before time runs out
- 1–4 players; larger groups share puzzle-solving roles

## Puzzle Deck
- Deck of riddle cards that present sequential puzzles
- Each puzzle produces a numeric answer (usually 1–3 digits)
- Card interactions combine images, text, and component artifacts

## Answer Mechanism
- The decoder (numbered dials) verifies answers without external tools
- Correct answers unlock the next card; wrong answers must be re-solved
- Answer structure constrains puzzle design to numeric outputs

## Progressive Hint System
- Every puzzle includes a multi-stage hint: clue → bigger hint → full solution
- Hints are revealed from the hint book by puzzle number
- Hint use costs time, trading difficulty for pace

## Consumable Components
- One-shot design: components are cut, folded, or marked as puzzles progress
- Destroying cards encodes solutions (e.g. folding reveals hidden text)
- Not replayable — the physical state is permanently altered

## Time Pressure
- Session timer frames the experience (though flexible in practice)
- Timer tension interacts with the hint system and difficulty

## Component Artifacts
- Small physical pieces (maps, letters, templates) used across puzzles
- Combining artifacts with cards is a core puzzle mechanic
