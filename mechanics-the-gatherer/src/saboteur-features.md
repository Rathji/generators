# Saboteur (Card Game) — Feature Reference

A system-level reference of the Saboteur card game (no content specifics). Useful as a checklist for designing hidden-role / cooperative-construction card games.

## Hidden Roles Core
- Players split into two secret teams: miners trying to reach treasure vs. saboteurs trying to block them
- Roles hidden until the end of each round (deduction during play)
- Player count scaling (3–10) adjusts the saboteur/miner split

## Tunnel Building
- Players play path cards that extend a tunnel from the start toward the treasure
- Path cards show connections (dead ends vs. through-tunnels)
- Saboteurs play blocked/dead-end paths to stall progress
- Shared visible tunnel state lets everyone read intentions

## Action Cards
- Tool cards (lanterns, picks, carts) needed for certain path actions
- Broken-tool cards that sabotage another player's abilities
- Repair cards to fix broken tools
- Rockfall cards that discard a path card from the tunnel
- Map cards that secretly reveal the location of the treasure card

## Round Structure
- Multiple rounds (e.g. three); players draw cards and play one per turn
- Hand limit and discard decisions
- End-of-round scoring distributed among winners based on team size

## Scoring & Meta-Game
- Points per round; highest total across all rounds wins
- Mining team shares points when they reach gold; saboteurs take points when they win
- Role distribution and points can shift between rounds

## Deduction Loop
- Reading path plays and tool usage to infer hidden roles
- Bluffing and suspicion are the core social layer
