# Operation — Feature Reference

A system-level reference of Operation's features (no content specifics). Useful as a checklist for designing precision/dexterity games that blend steady-hand skill with light risk-taking.

## Core Dexterity Loop
- Patient board with cavities holding removable ailment pieces
- Tweezers are the only allowed tool for extraction
- Extract a piece from its cavity without touching the metal edges
- Touching the edge completes a circuit and triggers the buzzer (fail state)

## Fail & Penalty Systems
- Buzzer (and optional nose flash) on edge contact
- Failed extraction penalizes the attempt (piece reset / card forfeited)
- Risk/reward: hasty play increases failure odds; slow play costs tempo

## Turn Structure
- Draw an ailment card assigning which piece to remove
- Attempt extraction; success clears the piece, failure carries a penalty
- Play passes to the next player after the attempt
- Game ends when all ailment pieces have been removed

## Scoring & Win Condition
- Fewest failed attempts wins (typical variant)
- Alternative: first player to complete a set of cards
- Per-player scorekeeping across rounds for campaign-style play

## Player Interaction
- Sequential turns (no simultaneous play)
- Indirect competition via score comparison
- Player count scaling: solo to small groups (2+)
