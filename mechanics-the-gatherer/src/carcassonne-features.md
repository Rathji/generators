# Carcassonne — Feature Reference

A system-level reference of Carcassonne's features (no content specifics). Useful as a checklist for designing tile-laying area-control games.

## Tile-Laying Core
- Players draw and place a tile each turn, extending a shared landscape
- Tiles must match edges (fields, roads, cities, monasteries)
- The map grows organically — placement shapes future play

## Meeple Placement
- Each placed tile may receive one follower (meeple)
- Followers claim features: roads, cities, fields, monasteries
- Feature ownership gives points when the feature completes

## Feature Scoring
- Completed roads and cities score immediately and return the meeple
- Unfinished features score less at game end
- Fields score via adjacent completed cities at game end

## Area Control & Blocking
- Features can be shared by multiple players' followers
- Joining a rival's feature makes ownership contested
- Placement choice is the only tactic — deny and steal features

## Turn Structure & Scaling
- Simple one-tile, one-meeple turn; the whole game is placement
- Scales 2–5 players (6 with expansion)
- Random tile draws give variety; zero hidden information

## Endgame
- The game ends when the tile supply runs out
- Final scoring resolves incomplete features and fields
- Short play time and deep spatial tactics
