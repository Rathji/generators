# Skip-Bo — Feature Reference

A system-level reference of Skip-Bo's features (no content specifics). Useful as a checklist for designing sequencing/shedding card games with multi-player discard piles.

## Sequencing Core
- Players build shared number sequences (1–12) in four central build piles
- Each build pile must be completed in ascending order from 1 to 12
- The first player to empty their personal stock pile wins

## Shared Build Piles
- All players can play onto any of the four build piles
- Build piles are communal — sequencing is a shared race
- Completion of a pile resets it for more building

## Personal Stock Pile
- Each player has a fixed-size personal draw deck to empty
- Drawing from stock is limited to a set number of cards per turn
- The stock is the win condition: empty it and you win

## Skip-Bo & Wild Cards
- Skip-Bo cards act as wilds that fill any number in a sequence
- Wilds are powerful and scarce — how to spend them matters
- Discarding a Skip-Bo loses it to the shared discard economy

## Multi-Player Discard Piles
- Each player runs a personal discard pile (up to a few cards per turn)
- Discards become future draw options — planning your own pile
- Card order in discard piles is fixed once placed

## Turn & Play Structure
- Draw a hand from stock, play sequences, discard to end the turn
- Multiple plays per turn allow combo sequencing
- Scales 2–6 players; gameplay stays simultaneous-ish and fast
