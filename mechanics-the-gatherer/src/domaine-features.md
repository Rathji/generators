# Domaine — Feature Reference

A system-level reference of Domaine's features (no content specifics). Useful as a checklist for designing area-enclosure territory games with fixed maps and border conflict.

## Fixed Board & Terrain
- Fixed grid board of numbered terrain tiles (e.g. 7×7, values 1–3)
- Terrain values define the scoring weight of each tile
- Tile arrangement is preset each game (or drawn/drafted for variety)

## Domain Building
- Players expand domains across the board from a starting homeland
- Borders are placed along grid lines to claim territory
- A domain's reach is limited by the borders of neighbors and the board edge

## Enclosure & Scoring
- A domain that is fully enclosed by borders (and/or board edge) resolves and scores
- Enclosed tiles are worth their terrain value to the enclosing player
- Enclosure timing creates a race: seal small domains fast vs. grow them large

## Castles & Defense
- Castles are placed to anchor/strengthen a player's presence in a region
- Castle counts as defensive force in conflicts
- Limited castle pool forces allocation choices

## Border Conflict
- Adjacent domains can attack each other across shared borders
- Conflict resolution compares the strength of both sides (castles + positioning)
- Losing a conflict costs territory or castle control

## Turn & Game Structure
- Single action per turn (place border or place castle)
- Game ends when the board is fully enclosed or pieces run out
- Player count scaling adjusts the map and starting conditions
