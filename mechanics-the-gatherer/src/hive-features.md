# Hive — Feature Reference

A system-level reference of Hive's features (no content specifics). Useful as a checklist for designing abstract placement games with full information and no randomness.

## Abstract Placement Core
- A pure abstract strategy game played with hexagonal bug tiles
- No board: the hive is built outward from a shared starting point
- No luck, no hidden information — perfect information dueling

## Bug Movement Rules
- Each bug type moves by its own rule (e.g. jump, crawl, fly, scuttle)
- Movement constraints create the strategic depth
- Every piece type is unique and asymmetric in capability

## Hex Connectivity & Placement Rules
- New pieces must be placed adjacent to your own pieces only
- The hive must stay connected at all times (no splitting)
- Placing pieces constrains movement — careful growth matters

## The Queen & Win Condition
- Surround the opponent's queen bee to win
- The queen must be played within a limited number of moves
- Queen placement is both a goal and a vulnerability

## Spatial Puzzle Dynamics
- Locking pieces in the hive is a common tactic (piece trapping)
- Escape options and surround threats drive the mid-game
- Games are short, replayable, and draw-possible

## Portability & Variants
- Fully portable (no board) — playable anywhere flat
- Expansions add bug types with new movement rules
- Scales exactly 2 players; tournament-friendly
