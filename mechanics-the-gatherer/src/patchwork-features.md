# Patchwork — Feature Reference

A system-level reference of Patchwork's features (no content specifics). Useful as a checklist for designing polyomino placement games with time tracks.

## Polyomino Placement Core
- Players build a personal quilt by placing polyomino pieces
- The quilt grid is fixed — placement is a spatial puzzle
- Pieces must fit the grid without overlap

## Time Track & Turn Order
- A shared time track determines who moves when
- Pieces cost buttons (currency) and time
- Moving ahead on the time track changes turn order

## Button Economy
- Buttons are both currency and the scoring track
- Spending buttons buys pieces; income is earned over time
- Efficient button use is the core economic puzzle

## Patch Variety
- Pieces have different shapes, costs, and time costs
- Some patches grant buttons or bonus tiles
- Piece availability rotates — the market is a shared display

## Negative Space & Penalties
- Unfilled grid spaces deduct points at game end
- Covering the grid efficiently is as important as filling it
- Penalty tiles (when you can't afford a piece) add pressure

## Endgame & Scoring
- The game ends when both players pass the finish on the time track
- Most buttons minus empty-space penalties wins
- Scales exactly 2 players; a modern classic abstract
