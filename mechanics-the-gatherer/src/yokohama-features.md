# Yokohama — Feature Reference

A system-level reference of Yokohama's features (no content specifics). Useful as a checklist for designing worker-placement games with a moving board (action tile).

## Worker Placement Core
- Players place workers on a shared action board each turn
- The board's key space (the focal point) moves each round
- Placement near the focal point is stronger — movement matters

## The Moving Focal Point
- Each turn the focal point tile is moved to a new action space
- Actions adjacent to it gain bonuses
- Predicting the focal point's path is the strategic layer

## Trade & Resource Economy
- Resources (tea, silk, gold) are produced and traded
- Ports and trade offices convert resources into points
- The trade network is a central scoring engine

## Technology & Upgrades
- Players buy technology upgrades that boost actions
- Upgrades create personal action asymmetries
- Tech investment competes with trade and points

## Orders & Objectives
- Order cards give delivery goals and bonuses
- Orders create short-term objectives
- Completing orders efficiently scores big

## Endgame & Scoring
- Fixed rounds; most points from trade, orders, and tech wins
- Scales 2–4 players; deep, interactive optimization
- Interaction via contested spaces and focal-point timing
