# Dungeon Lords — Feature Reference

A system-level reference of Dungeon Lords' features (no content specifics). Useful as a checklist for designing worker-placement games with dungeon building and event resolution.

## Dungeon Building Core
- Players build and defend a dungeon from invading heroes
- Each dungeon level hosts traps, monsters, and rooms
- The dungeon must be staffed and stocked before the assault

## Action Selection & Programming
- Players secretly choose actions each round (simultaneous programming)
- Actions are resolved in a fixed order — anticipation matters
- The action board is shared; conflicts over actions arise

## Trap & Monster Placement
- Traps occupy dungeon rooms; monsters guard them
- Placement must anticipate which rooms heroes will assault
- Room layouts and threat priorities shift with the game

## Hero Invasion & Combat
- At round's end, heroes invade and face the dungeon
- Combat resolves via the dungeon's defenses vs. hero strength
- Failed defenses cost points and dungeon integrity

## Building & Upgrade Economy
- Gold builds rooms and hires monsters
- Events and upgrades expand options each year (round)
- Resource scarcity forces prioritization

## Endgame & Scoring
- The game plays a fixed number of years/rounds
- Most dungeon prestige points wins
- Scales 2–4 players; the annual invasion cycle structures play
