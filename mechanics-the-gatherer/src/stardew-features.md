# Stardew Valley — Feature Reference

A system-level reference of Stardew Valley's features (no story/lore content). Useful as a checklist when designing farming/life-sim games.

## Core Loops
- Day/night cycle with a timed day (in-game clock, 28-day months, 4 seasons/year)
- Energy/stamina system (consumed by actions, exhaustion, food refills)
- Inventory management (slots, stacks, sort, chests, item pickup)
- Money/currency economy + shipping bin (sell harvested/foraged goods overnight)
- Save/load, seasons advance, weather system (rain, storms, lightning, wind, snow, random events)

## Skills & Progression
- 5 levelable skills (farming, mining, foraging, fishing, combat) + profession trees (level-up choices)
- Mastery system / endgame skill expansions
- Tool upgrade tiers (copper → iridium)
- Unlockables gated by skill level (recipes, crafting, machines)

## Farming & Ranching
- Crop lifecycle (till, plant, water, grow, harvest; seasonal crop calendars)
- Crop quality tiers + fertilizer types
- Sprinklers (irrigation automation)
- Animal husbandry (multiple species, housing upgrades, feeding/grazing, petting, product quality, hearts)
- Farm buildings (barns, coops, sheds, silos, greenhouses)
- Bee houses, fish ponds, other production structures
- Junimo huts / harvest automation

## Crafting, Cooking & Processing
- Crafting system (learned recipes, workbenches)
- Cooking system (kitchen, recipe unlocks, buffs)
- Machine processing (preserves, kegs, furnaces, recycling, looms, cheese/mayo, etc.)
- Resource refinement chains

## Gathering & Exploration
- Foraging (wild plants, fruit trees, tapping)
- Mining (procedural-ish mine floors, ores, gems, ladders)
- Combat (weapons, rings, boots, slingshot, health, death penalty, monster loot & goals)
- Fishing (casting minigame, bait/lures, crab pots, quality, seasonal/timed fish)
- Exploration maps (farm, town, forest, mountains, beach, desert, mines, island)

## Social & Relationship
- Friendship system (hearts per NPC, gifts, daily interactions, events)
- Marriage, romance, children, family life
- Festivals & events on a yearly calendar
- Pets (cat/dog adoption)

## Quests & Meta-Progression
- Bulletin board / help-wanted quests
- Story quest chain
- Collection/museum donations
- Achievements
- Special orders / long-term goals
- Secret/hidden objectives (notes, etc.)

## Building & Customization
- Farm layout choice at start + farm expansion
- Building placement/movement, farmhouse upgrades
- Character creation + customization options
- Decorating/furniture system
- Fast travel options (mine carts, etc.)

## Multiplayer & Tech
- Co-op multiplayer (shared farm, per-player progression)
- Save migration/transfer
- Modding support (mod loader ecosystem)
- Controller/keyboard support, UI scale/accessibility options
