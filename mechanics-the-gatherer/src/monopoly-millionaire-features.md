# Monopoly Millionaire — Feature Reference

A system-level reference of Monopoly Millionaire's features (no content specifics). Useful as a checklist for designing fast, simplified roll-and-move property trading games.

## Roll & Move Core
- Two dice determine movement around a square property track
- Landing on a property triggers a purchase decision
- Passing the start position pays a salary reward

## Property Acquisition
- Buy properties at listed prices when landing on them
- No auction mechanic — unowned property is simply bought or left
- Properties grouped into color sets

## Set Collection & Rent
- Rent escalates when a player owns a full color set
- Set ownership unlocks higher rent tiers
- Building/house rules simplified or absent vs classic Monopoly

## Event Cards
- Single card deck (Millionaire cards) replaces the Chance/Community Chest pair
- Cards trigger instant money changes, forced movement, or windfalls

## Accelerated Economy
- High starting capital in million-denomination bills
- Simplified money handling and small bill stack
- Slow mechanics (mortgaging, jail) removed to shorten play

## Turn & Game Structure
- Short, fast-paced session vs classic Monopoly
- Bankruptcy elimination; last player with money wins
- Player count scaling (2–4)
