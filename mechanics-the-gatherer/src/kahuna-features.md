# Kahuna — Feature Reference

A system-level reference of Kahuna's features (no content specifics). Useful as a checklist for designing two-player area-control games with card-driven placement.

## Two-Player Area Control
- Two players compete to control islands in an archipelago
- Control is determined by the number of bridges on an island
- Majority on each island scores points at scoring times

## Card-Driven Placement
- Each turn players draw island cards and use them to place bridges
- Card availability dictates placement options
- Cards must match the islands being bridged

## Bridge & Control Mechanics
- Bridges connect islands; more bridges = more control
- Unsupported bridges can be removed when opponents connect
- Securing control requires cutting opponent connections

## Card Limitation & Discard
- Hand limits cap how many cards you can hold
- Discarding strategically denies opponents card access
- The shared card draw makes denial a real strategy

## Scoring Rounds
- Fixed scoring points occur during the game
- The active player's islands score their current majorities
- Timing and control swings matter at each scoring

## Endgame
- The game ends after a fixed number of rounds
- Highest cumulative points wins
- Scales exactly 2 players; quick, tense dueling
