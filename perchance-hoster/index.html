How to use

  1. Pick an action — Download to my computer, Download + host to uploads.dev, Host to uploads.dev (get links), or Host files from my computer.
  2. Pick a host — the Host via dropdown chooses which service gets your links: user.uploads.dev (default), gofile.io (no setup, links expire ~10 days), tmpfiles.org (1-hour links, proxied), or keyed hosts (Supabase, Firebase, Cloudinary, S3-compatible (AWS / Cloudflare R2 / Google Cloud / B2 / Spaces…), Azure Blob (SAS URL), custom endpoint). Configure keys via the ⚙ settings button in the top-right.
  3. Choose a source — paste a URL list (name.mp3 | https://… or one bare URL per line), load the built-in ZREO catalogue JSON, or use the ZREO Archive (live) source.
  4. Load source — confirms how many files were found before you start.
  5. Start — watch the progress bar and log. If your browser asks about multiple downloads, click Allow.
  6. Host failover — if a host rejects a file (daily quota, bot-block, bad key), the batch automatically retries it on your next configured host. Watch for ↷ … trying next host… in the log. A file only counts as failed if every usable host rejects it.
  7. Stop / resume — every run is pause-safe: progress is saved in this browser, so you can Stop and continue later from the same browser.
  8. Grab your links — hosted files appear as name | url lines. Use Copy links, Copy JSON, or Download .md / .json to save the whole batch as a file (optionally named via the batch field) — then paste them straight back into the chat. Copy JSON also tags each link with which host produced it (provider) and any host note (note, e.g. expiry).

Hosts: user.uploads.dev gives permanent links (~5MB/file, ~30MB/day per IP) — files go to the Perchance host. gofile.io needs no setup but links expire. tmpfiles.org routes through Perchance's fetch proxy and keeps files 1 hour. The S3-compatible host covers AWS S3, Cloudflare R2, Google Cloud Storage, Backblaze B2, DigitalOcean Spaces, Wasabi, MinIO and more (signatures are computed in-browser; the endpoint/bucket must allow CORS). Azure Blob uploads with a container SAS URL. Keyed hosts store their keys in your browser only. Several other free hosts (catbox, 0x0.st, file.io, transfer.sh, pixeldrain) were tried but are unreachable or bot-blocked from the Perchance proxy, so they're not listed.

Failover: hosting tries the selected host first, then falls back to every other usable host (anonymous + configured keyed hosts) in order. A file only fails when all hosts reject it — so a single provider's quota or an outage won't stall a batch.

ZREO: the live source extracts the archive straight from zreoarchive.org; the built-in JSON catalogue carries the same 331 tracks offline.

Privacy: everything runs in your browser — the only network traffic is fetching the source files and uploading to the selected host.
