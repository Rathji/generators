How to use this dashboard

Three desks, one network — here's what each tab does and how to run it.

🌐 Tab 1 · Network Dashboard

  • Hit 🛰️ Scan the network — it fetches the hub's shelf list, adds plausible bgn-* candidates (including recent ones from the generator list), and probes each name against the Perchance API in batches.
  • Every result is checked for the BGN frame (8 chrome keys: hubUrl, gameTitle, gameTagline, gameKicker, gameGenre, gamePlayers, accentColor, heroImage), plus its hub link, tags, cover image, online support, views and last edit.
  • Use the status chips above the table to filter, and click any column header to sort.
  • Optionally list extra names (comma-separated) in the field below the scan button to check games not on the hub.

🐞 Tab 2 · Bug Triage

  • The dashboard can't reach the hub's server directly, so 🐞 Load hub bugs opens the hub in a small popup with a bridge flag; the hub asks for the review password and pushes its open bug list back.
  • Reports are grouped by game and duplicate titles/descriptions are flagged with a DUP chip.
  • Filter by game or by duplicates-only with the chips, and export everything to CSV with ⬇️ Export CSV.
  • If nothing loads, make sure popups are allowed for perchance.org.

🔄 Tab 3 · Template Updates

  • Hit 🔍 Scan template forks — every game on the hub is matched to its template via its header comment or its plugin/config signature.
  • Missing features show as a FEATURE GAP; a template edited after the fork shows as TEMPLATE UPDATED (a sign the shell may need a review).
  • Note: the public API doesn't expose a generator's index.html, so shell-level changes are caught via that edit-time staleness signal.
