Decompose any high-level project concept into granular, atomic task backlogs for AI coding agents — gated behind a strict planning-first hold. Then generate a ready-to-use starter prompt that bundles the roadmap with your chosen template for the build.

The generated kickoff prompt tells your agent to write the .pjs checklist and stay completely idle until you approve the backlog. Starter Prompt mode turns a roadmap into a ready-to-paste build prompt for your chosen template. Press R or Ctrl/⌘+Enter to regenerate.
