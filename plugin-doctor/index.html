📋 Standards

Every audit runs two layers:

  • Perchance best practices — a built-in checklist (list structure, $meta, DSL gotchas, security, docs, layout). Always on, not editable here.
  • Your standards — below. Add checks by hand, then export/import them as JSON to reuse across projects or share with a team. Saved automatically in your browser.

The checklist — what this tool checks for

Scoring. Required items are worth 3 points each, recommended 1 point, info items are un-scored. A missing required item drops the grade to at most C. Grade bands: A ≥ 90, B ≥ 80, C ≥ 70, D ≥ 60, else F.

Perchance best practices (built-in). Structure & $meta (title/description/image/tags, header mode = minimal, a clear import contract via $output or top-level functions), list structure & DSL (balanced brackets, no lines starting with \[, 2-space indentation, no if (x = …) assignment bug, parenthesized object literals, name() => function syntax), code quality (reading list args via .evaluateItem, never throwing on bad input, escaping user text before HTML injection, no document.write/eval), security (no secrets in public source, no insecure http://), docs & UX (usage examples, a visible <h1>, loading indicators), and HTML hygiene (text-align left override, no duplicate ids, viewport meta).

Your standards (custom checks). Each check has a label, category, level (required / recommended / info), a target (main.pjs / index.html / both), and a test. Tests are either a regex (must appear, must not appear, or appear at least N times) or a small JS function for advanced cases:

function(ctx) \{
  // ctx = \{ name, pjs, html, both, meta, imports, counts \}
  if (!/foo/.test(ctx.pjs)) return \{ st: "fail", det: "missing foo" \};
  return \{ st: "pass" \};
\}

Every check can carry a hint (shown on failure and included in the AI-helper fix prompt) and an optional waive-if regex — if it matches the source, the check is marked n/a.

JSON format. Export produces an object with a name and a checks array; import accepts that object or a bare array of check objects. Check fields: id, label, category, level, target, mode (regex_present | regex_absent | regex_count | js), pattern, flags, minCount, js, waiveIf, hint, enabled.

🛡️ Self-check — run from a plugin's own AI helper

Give any plugin a one-click self-check. Click below to copy an AI-helper prompt; paste it into the target plugin's AI helper and it adds a Check standards link to the plugin's page. Clicking that link opens plugin-doctor in a popup, pre-loaded with the plugin's own name, and runs the audit automatically.

Alternatively, copy the report or fix-prompt (buttons on any audit card) and paste them straight into the plugin's AI helper to have it fix issues directly.
