How to use music-category-tagger

Paste a file list → get a categorized Perchance audio engine + a working player.

1 · Paste your file list

Drops into the top textarea — or use 📂 Open file / drag-and-drop a .txt or .csv export. Accepts PowerShell Get-ChildItem rows, ls -la rows, plain filenames (with or without leading track numbers like 01. or 01 -), paths like ./audio/, and full URLs. Only audio files are kept (.mp3 .ogg .flac .mid .wav .m4a .wma .aac .opus).

2 · Set the base URL

Prepended to bare filenames so generated file URLs resolve, e.g. https://archive.org/download/my-soundtrack-repo/ or ./audio/. Full URLs and relative paths pass through unchanged.

3 · Generate

Press ⚙ Generate — or just keep typing, the tool regenerates live.

How tracks are categorized

Every track is tagged on four axes:

  1. Type — loop-bgm, active-bgm, stinger, or skip
  2. Mood — peaceful, ambient, tense, heroic, mysterious, cheerful, melancholic, creepy
  3. Environment — town, dungeon, field, tavern, cutscene, battle, shop, sacred, indoor
  4. Sound profile — acoustic, piano, harp, strings, woodwinds, orchestral, synth, chiptune, heavy-percussion, minimal

Fix a wrong guess with the per-row Type dropdown — the generated code updates instantly.

Outputs

Copy Perchance Code → the audioTracks hierarchy plus filtered selectors (calmBackgroundList, townExplorationList, dungeonAmbientList, stingerFanfares) for your generator's main.pjs.

Copy HTML Player → an HTML5 player with Play/Pause, Skip, volume, pool switching and fallback error handling for index.html.

Export results → a Markdown report or structured JSON of the categorized tracks.

Custom selector pools → define extra filtered lists (name + type/mood/tag conditions, is / is not) that are generated into the code, the player's pool dropdown, the preview and the exports.

Share → copies a link with your file list and base URL embedded, so a configured tool state is bookmarkable and sendable.

The ▶ button on any table row plays that track instantly.

Using it in your generator

Inside a square block: assign t = calmBackgroundList.selectOne, then read t.file, t.title, t.mood…

In a script: let pool = calmBackgroundList; then pick with pool.selectOne.

Tuning the categorizer

Keyword dictionaries (audioHeurSkip, audioHeurStinger, audioHeurMoods, …) are editable lists at the top of main.pjs — tweak them and the tool re-categorizes with your rules.

🎼 music-category-tagger

Paste a raw audio file list and music-category-tagger builds you a complete Perchance audio engine: a categorized audioTracks list, filtered selectors for calm / town / dungeon / stinger pools, and a copy-ready HTML5 player. A Rathji template-based tool.

What it does

Drop in a directory listing — PowerShell Get-ChildItem, ls -la, or plain newline-separated filenames — plus a base URL (e.g. https://archive.org/download/my-soundtrack-repo/ or ./audio/). The tool cleans and normalizes every track, tags it across four axes, then generates valid Perchance hierarchical code and a working player for it.

3. Generated Perchance code

Two ready-to-paste outputs. Copy Perchance Code goes into your generator's main.pjs; Copy HTML Player goes into its index.html. The selectors are filtered arrays with a .selectOne attached, so both of these work in your generator:

  • In a template: inside a square block, t = calmBackgroundList.selectOne → then read t.file, t.title, t.mood…
  • In a script: let pool = calmBackgroundList; → pick with pool.selectOne.

4. Live player preview

The same playback logic the generated player uses, running against your parsed tracks. Files load from your base URL — if they 404, the fallback error handling kicks in and it skips to the next track.

Notes

  • Parsing strips track numbers (01. , 01 - ), extensions (.mp3 .ogg .flac .mid …), and table columns from directory listings; it keeps bare filenames and full URLs as-is.
  • Keys are generated as unique camelCase (collisions get a number suffix) and are valid JS identifiers.
  • If a track is already a full URL, it's used verbatim — the base URL is only prepended to bare filenames.
  • Keyword dictionaries (audioHeurSkip, audioHeurMoods, …) are editable lists at the top of main.pjs — tweak them to tune the categorizer.
  • The generated player never autoplays until you press ▶ (browsers block sound before a user gesture).
  • This page doubles as docs and a test harness: Load sample, then try overriding types or pointing the base URL at a real archive.
