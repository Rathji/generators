🕹 vgn-rom-plugin

NES · SNES · Master System · Mega Drive — disassembly & pseudo-C

Load a retro console ROM and it is automatically disassembled, the functions are rebuilt into readable pseudo-C, and the tiles & palettes are extracted. A small NES demo ROM is pre-loaded — drop any .nes / .sfc / .sms / .md file in the box to switch.
