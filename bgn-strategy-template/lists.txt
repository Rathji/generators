// ════════════════════════════════════════════════════════════════════════
//  BGN STRATEGY TEMPLATE — REMIX GUIDE
//  ────────────────────────────────────────────────────────────────────────
//  This whole generator is a strategy-game template. The engine lives in
//  index.html and reads EVERYTHING below: powers, resources, phases, tuning.
//
//  To make your own strategy game:
//   1. Fork this generator. 2. Edit the lists below. 3. (optional) Replace
//      the world map in src/mapdata.js. 4. Tweak the phase handlers & AI in
//      index.html. The demo (Supremacy 1984) stays playable until you do.
//
//  What lives where:
//   • templateName / gameTitle / gameSubtitle / tagline / accentColor / maxPlayers — branding
//     (templateName shows in the page header & setup screen; gameTitle is the demo game's title)
//   • powers        — who plays, their colours, home zones, supply centre, home sea
//   • resources     — the trade goods; `price` is the opening world-market price
//   • phases        — the turn order; each phase key maps to a handler in index.html
//   • tune          — every number the engine uses (costs, income, caps, AI tiers)
//   • src/mapdata.js — the territory grid (see its header comment for the format)
//
//  Zone keys in `homes` / `supply` / `navy` must match zone ids in
//  src/mapdata.js (land ids 1..N, sea ids 101..N+100). Unknown keys are
//  skipped, so a missing zone degrades gracefully instead of crashing.
// ════════════════════════════════════════════════════════════════════════
